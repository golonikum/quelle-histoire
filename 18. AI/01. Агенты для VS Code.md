# AI-агенты для VS Code

**Cline** (ранее известный как `Claude Dev`) и его популярный форк **Roo Code** — это ведущие автономные AI-агенты с открытым исходным кодом, работающие в виде расширения прямо внутри `VS Code`.

В отличие от стандартных автокомплитов, они превращают боковую панель VS Code в полноценного цифрового напарника, управляющего файлами, терминалом и инструментами.

## 1. Как устроен рабочий процесс (Human-in-the-Loop)

Агент действует пошагово через панель задач, где для каждого потенциально опасного действия запрашивает одобрение разработчика:

1. Исследование: агент сканирует структуру проекта, читает нужные файлы и строит план.

2. Интерактивный `Diff`: перед изменением кода плагин открывает стандартный сплит-экран VS Code с подсветкой удаленных/добавленных строк.

3. Исполнение терминала: агент может сам сформировать команду (например, `npm install lodash` или `npm test`), но запустит её только после нажатия кнопки `Approve` (или в режиме `Auto-Approve`, если вы доверяете агенту).

4. Интеграция с браузером: умеет открывать веб-страницу локального сервера, кликать по кнопкам и делать скриншоты для проверки рендеринга.

## 2. Поддержка MCP (Model Context Protocol)

Одной из главных фич экосистемы является встроенная поддержка протокола MCP от Anthropic:

- Вы можете подключить к агенту внешние MCP-серверы: базы данных (`PostgreSQL`, SQLite), локальную документацию, `GitHub/GitLab API`, `Figma` или `Slack`.
- Агент может выполнять SQL-запросы к тестовой БД для проверки схемы, читать компоненты из `Figma` или создавать `Pull Request` прямо по ходу выполнения задачи.
- В `Cline` встроен каталог `MCP Marketplace` для установки серверов в один клик.

## 3. В чем разница между Cline и Roo Code

| Критерий            | Cline (Оригинал)                                | Roo Code (Форк)                                                                                         |
| ------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Архитектура режимов | Двухфазный цикл: Plan (планирование без правок) | Ролевые режимы: `Architect`, `Code`, `Ask`, `Debug`.                                                    |
| Кастомные режимы    | Базовые настройки системного промпта.           | Полноценный файл `.roomodes` с гибким ограничением разрешенных инструментов и моделей под каждую роль . |
| Экономия токенов    | Стандартный дифф-механизм.                      | Оптимизированный алгоритм `apply_diff` (существенная экономия контекста).                               |
| Статус проекта      | Активно развивается сообществом и создателем.   | Форк с расширенным набором экспериментальных фич.                                                       |

## Вердикт и рекомендация

- Если вы хотите платить меньше за API-токены и иметь четкий контроль (чтобы агент сначала спланировал архитектуру в режиме Architect, а затем реализовал её в Code через дешевый DeepSeek или точный Claude) — выбирайте `Roo Code`.
- Если вам нужен минималистичный инструмент без лишних меню и с гарантированной стабильностью апдейтов — ставьте `Cline`.

## Подключение API

### Вариант 1: Бесплатные облачные API (быстро и без нагрузки на ПК)

Некоторые крупные провайдеры предоставляют щедрые бесплатные лимиты (`Free Tier`) без необходимости вводить данные банковской карты.

1. **Google AI Studio (Gemini Flash)** — Лучшее качество из бесплатных
   **Что дают**: Бесплатный доступ к Gemini 2.5 Flash / 1.5 Pro с огромным контекстным окном (до 1M токенов).
   **Лимиты**: До 15 запросов в минуту (RPM) и до 1500 запросов в день — для личной разработки хватает с запасом.
   **Как настроить**:
   - Зайдите на `aistudio.google.com` через Google-аккаунт и нажмите `Get API key`.
   - В настройках `Roo Code` / `Cline` выберите провайдер `Google Gemini` (или `OpenAI-Compatible`).
   - Вставьте ключ.

2. **Groq Cloud (Сверхбыстрый Llama / Qwen)**
   **Что дают**: Бесплатный доступ к Llama 3.3 70B и DeepSeek / Qwen на специализированных чипах LPU (скорость генерации до 300–500 токенов/сек).
   **Лимиты**: До 30 запросов в минуту, до 1000 запросов в день.
   **Как настроить**:
   - Зарегистрируйтесь на `console.groq.com` и создайте ключ в разделе `API Keys`.
   - В `Roo Code` выберите провайдер `Groq`, модель `llama-3.3-70b-versatile` или `qwen-2.5-coder`.

3. **OpenRouter (Free Models)**
   **Что дают**: Доступ к десяткам бесплатных моделей с суффиксом `:free` (например, `meta-llama/llama-3.3-70b-instruct:free`, `qwen/qwen-2.5-coder-32b-instruct:free`).
   **Как настроить**: Зарегистрируйтесь на `openrouter.ai` (через `GitHub/Google`), создайте ключ, выберите провайдер `OpenRouter` в плагине и укажите модель с тегом `:free`.

### Вариант 2: Полностью локально через Ollama (100% бесплатно и оффлайн)

Если у вас нормальная видеокарта (`NVIDIA 8GB+ VRAM` или `16GB+` оперативной памяти), агент может работать прямо на вашем железе без интернета и ограничений.

1. Установите Ollama:
   - Скачайте с ollama.com (для Windows / Linux / macOS).

2. Скачайте модель для кодинга (Qwen 2.5 Coder — топ для локалок):
   - Для видеокарт/ПК с 8–16 ГБ RAM:

   ```bash
   ollama pull qwen2.5-coder:7b
   ```

   - Для мощных ПК с 32 ГБ+ RAM:

   ```bash
   ollama pull qwen2.5-coder:32b
   ```

3. Подключите в `Roo Code` / `Cline`:

- Провайдер: `Ollama`.
- Base URL: `http://localhost:11434`.
- Model ID: `qwen2.5-coder:7b` (или `qwen2.5-coder:32b`).
