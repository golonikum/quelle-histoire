# Транспортный уровень

## TCP (Transmission Control Protocol)

**TCP** — это надежный протокол передачи данных в сети, который устанавливает соединение между двумя узлами и гарантирует порядок доставки пакетов.

- Работает поверх IP и обычно используется там, где важны надежность и правильная последовательность данных.
- Перед передачей устанавливает соединение через **three-way handshake**: SYN → SYN-ACK → ACK.
- Если пакет потерялся или пришел с ошибкой, TCP переотправляет данные.

## SCTP (Stream Control Transmission Protocol)

**SCTP** — это транспортный протокол, который сочетает надежность TCP с сообщениями и многопоточностью, а не одним байтовым потоком. Он был изначально создан для передачи сигнализации, но подходит и для других задач.

![SCTP](./images/05.%20SCTP.png)

## UDP (User Datagram Protocol)

**UDP** — это легкий, безустановочный транспортный протокол: он просто отправляет датаграммы без подтверждений, повторной передачи и гарантий порядка.

![UDP сегмент](./images/05.%20UDP%20сегмент.png)

## DCCP (Datagram Congestion Control Protocol)

**DCCP** — это транспортный протокол для ненадежных датаграмм, но с контролем перегрузки.

- Похож на UDP тем, что не гарантирует доставку и порядок пакетов.
- Похож на TCP тем, что умеет управлять перегрузкой в сети.
- Подходит для потокового видео, VoIP и игр, где важнее своевременность, чем идеальная надежность.

## Утилиты для анализа сетевого трафика

### netstat

`netstat` — консольная утилита для просмотра сетевых соединений, открытых портов и маршрутов.

```
netstat -a                 // Все подключения и слушающие порты
netstat -s -e              // Статистика Ethernet и протоколов (IP, TCP, UDP и т.д.)
netstat -ano               // все, не делать DNS‑резолв, показать PID процесса
netstat -b                 // имя исполняемого файла
netstat -an | find ":80"   // кто слушает/использует конкретный порт (пример для 80)
netstat -anp tcp           // фильтрация по протоколу
netstat -r                 // Таблица маршрутизации (аналог route print)
netstat -ano 5             // Обновлять список каждые 5 секунд (пока не прервёшь Ctrl+C)
```

### Wireshark

**Wireshark** — это бесплатный графический анализатор сетевого трафика, который захватывает и показывает пакеты «вживую» по разным интерфейсам (Ethernet, Wi‑Fi и др.) и умеет разбирать сотни протоколов по полям. Подключается к сетевому адаптеру и захватывает пакеты через pcap/WinPcap/libpcap, может работать в promiscuous‑режиме. Отображает поток пакетов и позволяет фильтровать (display filters), декодировать содержимое и сохранять дампы для дальнейшего анализа.

### tcpdump

**tcpdump** — консольный сниффер для Linux/Unix, который захватывает и показывает сетевые пакеты с интерфейсов в реальном времени или пишет их в файл для последующего анализа.

```
tcpdump -i eth0                 // Захват с интерфейса
tcpdump -i eth0 tcp port 80     // Только HTTP‑трафик
tcpdump -i eth0 -w traffic.pcap // Записать в файл
```

## NAT (Netwrok Address Translation)

**NAT** (Network Address Translation) — это механизм на маршрутизаторе/шлюзе, который подменяет IP‑адреса (и часто порты) в проходящих пакетах, чтобы множество внутренних хостов могли использовать один или несколько внешних адресов и при этом быть недоступными напрямую снаружи.

Типы NAT:

- **Статический NAT** - один IP-адрес на один IP-адрес
- **Динамический NAT** - много IP-адресов на несколько IP-адресов
- **Перегруженный NAT (PAT)** - много IP-адресов на один IP-адрес

![Перегруженный NAT](./images/05.%20Перегруженный%20NAT.png)

### Настройка NAT-PAT в Cisco CLI

Исключаем из аннонсирования сеть в RIP (возможно понадобится перезагрузка устройств):

```
Router>enable
Router#conf t
Router(config)#router rip
Router(config-router)#ver 2
Router(config-router)#no network 192.168.1.0
Router(config-router)#exit
Router(config)#
```

Добавляем NAT:

```
Router>enable
Router#conf t
Router(config)#access-list 1 permit 192.168.1.0 0.0.0.255
Router(config)#exit
```

Указываем какой тип NAT мы хотим использовать:

```
Router>enable
Router#conf t
Router(config)#ip nat inside source list 1 int fa0/1 overload
Router(config)#int fa0/0
Router(config-if)#ip nat inside
Router(config-if)#exit
Router(config)#int fa0/1
Router(config-if)#ip nat outside
Router(config-if)#exit
```

Проверка (после ping узла):

```
Router#show ip nat translations
```
