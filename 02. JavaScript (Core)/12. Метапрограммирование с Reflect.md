## Метапрограммирование с Reflect

**Метапрограммирование** — это когда код изменяет поведение **других объектов/API во время выполнения**. Reflect + Proxy дают суперсилу для динамического создания/модификации API объектов.

## 1. Динамический API с валидацией

```javascript
const createValidatedUser = () => {
  const handler = {
    set(target, prop, value, receiver) {
      // Динамическая валидация
      if (prop === "email" && !value.includes("@")) {
        throw new Error("Некорректный email");
      }
      if (prop === "age" && (value < 0 || value > 150)) {
        throw new Error("Возраст вне диапазона");
      }
      return Reflect.set(target, prop, value, receiver);
    },
    get(target, prop, receiver) {
      if (prop === "fullName") {
        // Динамический computed property
        return `${target.firstName || ""} ${target.lastName || ""}`.trim();
      }
      return Reflect.get(target, prop, receiver);
    },
  };
  return new Proxy({}, handler);
};

const user = createValidatedUser();
user.firstName = "Алексей";
user.lastName = "Иванов";
console.log(user.fullName); // "Алексей Иванов"
user.email = "test"; // Error: Некорректный email
```

## 2. Observable (реактивная система)

```javascript
class Observable {
  constructor() {
    return new Proxy(this, {
      set(target, prop, value, receiver) {
        const oldValue = target[prop];
        const result = Reflect.set(target, prop, value, receiver);

        // Уведомляем подписчиков
        if (result && oldValue !== value) {
          target.notify(prop, oldValue, value);
        }
        return result;
      },
    });
  }

  notify(prop, oldValue, newValue) {
    for (let listener of this.listeners || []) {
      listener(prop, oldValue, newValue);
    }
  }

  subscribe(listener) {
    this.listeners = this.listeners || [];
    this.listeners.push(listener);
  }
}

const model = new Observable();
model.subscribe((prop, old, newVal) => {
  console.log(`${prop}: ${old} → ${newVal}`);
});

model.count = 1; // count: undefined → 1
model.count = 42; // count: 1 → 42
```

## 3. Lazy Properties (ленивая инициализация)

```javascript
const createLazyObject = (config) => {
  const cache = new Map();

  return new Proxy(
    {},
    {
      get(target, prop, receiver) {
        if (!cache.has(prop)) {
          const creator = config[prop];
          if (typeof creator === "function") {
            cache.set(prop, creator());
          } else {
            return creator;
          }
        }
        return Reflect.get(cache, prop);
      },
    },
  );
};

const api = createLazyObject({
  users: () => fetch("/api/users").then((r) => r.json()),
  posts: () => fetch("/api/posts").then((r) => r.json()),
  config: { theme: "dark" },
});

console.log(api.config.theme); // { theme: 'dark' } — сразу
api.users.then(console.log); // Promise — лениво
```

## 4. Динамическая маршрутизация методов

```javascript
const createApiClient = (baseUrl) => {
  return new Proxy({}, {
    get(target, method) {
      if (method === 'request') {
        return (endpoint, options = {}) =>
          fetch(`${baseUrl}${endpoint}`, options)
            .then(r => r.json());
      }

      // Динамически создаем метод: api.users.list(), api.users.create()
      return function dynamicMethod(...args) {
        const [resource, action] = method.toString().split('.');
        return target.request(`/${resource}/${action}`, {
          method: action === 'create' ? 'POST' : 'GET',
          body: args[^0] ? JSON.stringify(args[^0]) : undefined
        });
      };
    }
  });
};

const api = createApiClient('https://myapi.com');
api.users.list();     // GET /users/list
api.users.create({name: 'Alex'});  // POST /users/create
```

## 5. Auto-freeze (immutable API)

```javascript
const createImmutable = (obj) =>
  new Proxy(obj, {
    set() {
      throw new Error("Объект неизменяемый!");
    },
    get(target, prop, receiver) {
      const value = Reflect.get(target, prop, receiver);
      return typeof value === "object" ? createImmutable(value) : value;
    },
  });

const state = createImmutable({ user: { name: "Alex" } });
console.log(state.user.name); // 'Alex'
state.user.name = "Bob"; // Error!
```

## Ключевые паттерны

| Паттерн       | Пример Reflect                  |
| :------------ | :------------------------------ |
| **Валидация** | `Reflect.set()` + проверки      |
| **Logging**   | `Reflect.get/set` + console.log |
| **Lazy**      | `Reflect.get()` + кэш/Map       |
| **Reactive**  | `Reflect.set()` + уведомления   |
| **Immutable** | `Reflect.set()` → throw         |

**Для мидл/синьора:** Это основа signals (Preact Signals), Vue 3 reactivity, Zustand под капотом. Понимаешь Reflect/Proxy → можешь создать свою state management библиотеку за день.
