# Temporal

**Temporal API** — это новый стандарт JavaScript (Stage 4, ожидается в 2026–2027), который заменяет проблемный `Date` на иммутабельные классы для точной работы с датами, временем и часовыми поясами.

Temporal решает исторические баги `Date`: мутабельность, неточность миллисекунд, проблемы с UTC/локалью и leap seconds.

## Основные классы Temporal

```javascript
// Глобальный объект (как Math)
console.log(Temporal.Now); // Текущее время

// 1. Точное время (Unix timestamp)
const instant = Temporal.Instant.from("2026-03-23T18:50:00Z");

// 2. Дата без времени (ISO или локальная)
const date = Temporal.PlainDate.from("2026-03-23"); // YYYY-MM-DD

// 3. Дата+время без часового пояса
const dateTime = Temporal.PlainDateTime.from("2026-03-23T18:50:00");

// 4. Дата+время+часовой пояс (замена Date)
const zoned = Temporal.ZonedDateTime.from("2026-03-23T18:50:00[Europe/Moscow]");
```

## Практические примеры (ваш стек)

**React компонент с датами:**

```tsx
import { useMemo } from "react";

function EventDate({ isoString }: { isoString: string }) {
  const zonedDate = useMemo(
    () => Temporal.ZonedDateTime.from(isoString + "[Europe/Moscow]"),
    [isoString],
  );

  return (
    <time dateTime={zonedDate.toString()}>
      {zonedDate.toLocaleString("ru", {
        weekday: "long",
        month: "long",
        day: "numeric",
        hour: "numeric",
        timeZoneName: "short",
      })}
    </time>
  );
}
```

**Работа с разницей во времени:**

```javascript
const moscow = Temporal.ZonedDateTime.from(
  "2026-03-23T18:50:00[Europe/Moscow]",
);
const ny = moscow.toZonedDateTimeISO("America/New_York");
console.log(ny.toString()); // 2026-03-23T11:50:00-04:00[America/New_York]
```

## Преимущества над Date

| Проблема Date                | Решение Temporal                |
| :--------------------------- | :------------------------------ |
| `new Date()` мутируется      | Всегда иммутабельно             |
| Нет поддержки часовых поясов | `ZonedDateTime` с IANA          |
| Проблемы с leap seconds      | `Instant` точен до наносекунд   |
| `getTimezoneOffset()` баги   | Встроенная `toZone()`           |
| Парсинг строк ненадёжен      | Стандартные форматы + календари |

## Temporal.Duration

**`Temporal.Duration`** представляет продолжительность времени в различных единицах (годы, месяцы, недели, дни, часы, минуты, секунды, миллисекунды, микросекунды, наносекунды) с иммутабельной семантикой — все операции возвращают новые объекты.

### Создание Duration

```javascript
// Конструктор: years, months, weeks, days, hours, minutes, seconds, milliseconds, microseconds, nanoseconds
const duration = new Temporal.Duration(1, 2, 3, 4, 5, 30, 45, 123, 456, 789);
// PT1Y2M3W4DT5H30M45.123456789S (ISO 8601)

const fromObject = Temporal.Duration.from({
  years: 1,
  months: 2,
  days: 4,
});

const fromString = Temporal.Duration.from("P1Y2M3W4DT5H30M45S");
```

### Основные методы

**Арифметика (иммутабельно):**

```javascript
const dur1 = Temporal.Duration.from({ days: 5 });
const dur2 = Temporal.Duration.from({ hours: 12 });

// Сложение
const sum = dur1.add(dur2); // 5 дней + 12 часов

// Вычитание
const diff = dur1.subtract(dur2); // 5 дней - 12 часов

// Инверсия
const negated = dur1.negated(); // -5 дней
```

**Округление и балансировка:**

```javascript
const rough = Temporal.Duration.from({ days: 1, hours: 24 });
const rounded = rough.round({ largestUnit: "day" });
// Результат: 2 дня (балансирует часы в дни)
```

**Полезные свойства:**

```javascript
const dur = Temporal.Duration.from({ days: 3, hours: 12 });
console.log(dur.sign); // 1 (положительная)
console.log(dur.blank); // false
console.log(dur.total("days")); // 3.5 (общее в днях)
```

### Практика для вашего проекта АПК

**Таймер дежурства оператора:**

```tsx
function ShiftTimer({ startTime }: { startTime: string }) {
  const now = Temporal.Now.zonedDateTimeISO();
  const shiftStart = Temporal.ZonedDateTime.from(startTime);
  const duration = now.since(shiftStart); // Автоматически Duration

  return (
    <div>
      Прошло:{" "}
      {duration.toLocaleString("ru", {
        style: "short",
        unit: "hour",
      })}
    </div>
  );
}
```

**Разница между событиями с камер:**

```javascript
const event1 = Temporal.ZonedDateTime.from(
  "2026-03-23T18:50:00[Europe/Moscow]",
);
const event2 = Temporal.ZonedDateTime.from(
  "2026-03-23T19:15:30[Europe/Moscow]",
);
const delta = event2.since(event1); // Duration 25 мин 30 сек
```

### Ключевые отличия от setTimeout/setInterval

| Date/setTimeout | Temporal.Duration                |
| :-------------- | :------------------------------- |
| Мутабельность   | Полностью иммутабельно           |
| Часовые пояса   | Полная поддержка IANA            |
| Точность        | Наносекунды                      |
| Арифметика      | `add()`, `subtract()`, `round()` |
| Формат          | Стандартизированный ISO 8601     |

**Для React**: Всегда используйте `useMemo` для Duration вычислений — они "тяжёлые", но кэшируются отлично.
