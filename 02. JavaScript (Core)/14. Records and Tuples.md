# Records and Tuples

**Records and Tuples** — это **экспериментальное предложение TC39** (Stage 2, не вошло в стандарт), добавляющее **иммутабельные примитивы** с **глубоким равенством** (`===` по значению, а не по ссылке). Синтаксис: `#{...}` для records, `#[...]` для tuples.

## Основные фичи

### **1. Иммутабельность (глубокая)**

```javascript
// ❌ Объекты мутируются
const obj1 = { a: 1 };
const obj2 = { a: 1 };
obj1 === obj2; // false (разные ссылки)

// ✅ Records/Tuples — неизменяемы
const record1 = #{ a: 1 };
const record2 = #{ a: 1 };
record1 === record2; // true (глубокое равенство)

const tuple1 = #[1, 2, 3];
const tuple2 = #[1, 2, 3];
tuple1 === tuple2; // true
```

### **2. Синтаксис (почти как объекты/массивы)**

```javascript
const person = #{ name: "Иван", age: 30 };
const coords = #[55.75, 37.62]; // СПб координаты
const camera = #{ id: 123, status: "online", pos: #[59.93, 30.31] };
```

### **3. Обновление (иммутабельно)**

```javascript
// Создаём НОВЫЙ record/tuple
const updated = #{ ...person, age: 31 };
const filtered = person.pos.slice(0, 1); // tuple.slice()

updated === person; // false (новый объект)
```

## Сравнение с Object.freeze()

| Object.freeze()                   | Records/Tuples             |
| :-------------------------------- | :------------------------- |
| **Поверхностная** иммутабельность | **Глубокая** (рекурсивная) |
| `===` по ссылке                   | `===` **по значению**      |
| Не примитив                       | **Примитивы**              |
| Можно разморозить                 | **Невозможно**             |

## Практика для React/Next.js

**1. State без useMemo:**

```tsx
function CameraList({ cameras }: { cameras: Camera[] }) {
  // ✅ Tuples как ключи React
  const cameraTuple = #[camera.id, camera.status];

  return cameras.map(camera => {
    const keyTuple = #[camera.id, camera.status];
    return <CameraCard key={keyTuple} camera={camera} />;
  });
}
```

**2. Memoization без библиотек:**

```tsx
const CameraKey = #{ id: 123, pos: #[59.93, 30.31] };
const cache = new Map();
if (cache.has(CameraKey)) {
  return cache.get(CameraKey); // Работает!
}
```

## Текущий статус (апрель 2026)

- **Stage 2** (не стабильно)
- **Polyfill**: `@record/tuple` (Babel plugin)
- **Не в V8/SpiderMonkey** (нативно)

**Установка polyfill:**

```bash
npm i @record/tuple
```

```javascript
import { Record, Tuple } from "@record/tuple";

const person = Record({ name: "Иван", age: 30 });
const coords = Tuple(59.93, 30.31);
```

## Когда использовать (если станет стандартом)

**✅ Идеально для:**

```
- React keys (глубокое равенство)
- Map/Set ключи (структуры данных)
- Redux/Zustand state (иммутабельность)
- Кэширование (coordinates, camera IDs)
```

**Вывод**: **Records/Tuples = immutable примитивы с value equality**. Ждём Stage 4 (~2027–2028). Пока — Immer или `Object.freeze(deep)`.
