# Новые фичи React 19

React 19, выпущенный в декабре 2024 года, ввёл множество улучшений для форм, асинхронных операций, производительности и серверного рендеринга. Ключевые новинки — новые хуки (useActionState, useOptimistic, use, useFormStatus), Actions для упрощения мутаций данных, React Compiler (экспериментальный) и поддержка Server Components.

## Новые хуки для форм и Actions

Actions — это async-функции в переходах (useTransition), которые автоматически управляют pending-состоянием, ошибками и optimistic updates. Они интегрируются с <form>.

**useActionState**: Возвращает [state, action, isPending] для обработки результатов Actions.

```jsx
import { useActionState } from "react";

function UpdateProfile({ userId }) {
  const [error, submitAction, isPending] = useActionState(
    async (prevState, formData) => {
      const name = formData.get("name");
      const result = await updateProfile(userId, name);
      if (result.error) return result.error;
      return null;
    },
    null,
  );

  return (
    <form action={submitAction}>
      <input name="name" />
      <button disabled={isPending}>Update</button>
      {error && <p>{error}</p>}
    </form>
  );
}
```

Автоматически сбрасывает форму при успехе.

**useFormStatus** (в react-dom): Читает статус родительской формы без prop drilling.

```jsx
import { useFormStatus } from "react-dom";

function SubmitButton() {
  const { pending } = useFormStatus();
  return <button disabled={pending}>Submit</button>;
}

// В форме: <form action={action}><SubmitButton /></form>
```

Идеально для дизайн-систем.

## Optimistic UI и useOptimistic

Показывает изменения мгновенно, пока сервер подтверждает.

```jsx
import { useOptimistic } from "react";

function Likes({ likes, userId, onUpdate }) {
  const [optimisticLikes, setOptimisticLikes] = useOptimistic(likes);

  const submitAction = useActionState(async (_, formData) => {
    setOptimisticLikes(likes + 1); // Оптимистично
    const newLikes = await updateLikes(userId);
    onUpdate(newLikes);
  }, null);

  return (
    <form action={submitAction}>
      <p>Likes: {optimisticLikes}</p>
      <button>👍</button>
    </form>
  );
}
```

При ошибке автоматически откатывается.

## Хук use()

Читает промисы или контекст в render, suspends до разрешения. Только стабильные ресурсы (не создавать в render).

```jsx
import { use } from "react";

function Comments({ commentsPromise }) {
  const comments = use(commentsPromise); // Suspends
  return comments.map((c) => <p key={c.id}>{c.text}</p>);
}

function App() {
  return (
    <Suspense fallback={<div>Загрузка...</div>}>
      <Comments commentsPromise={fetchComments()} />
    </Suspense>
  );
}
```

Вы также можете считывать контекст с помощью `use` + поддержка условного use после early returns:

```jsx
import { use } from "react";
import ThemeContext from "./ThemeContext";

function Heading({ children }) {
  if (children == null) {
    return null;
  }

  // This would not work with useContext
  // because of the early return.
  const theme = use(ThemeContext);
  return <h1 style={{ color: theme.color }}>{children}</h1>;
}
```

## Улучшения ref и Context

- **ref как проп**: Не нужен `forwardRef`.

```jsx
function MyInput({ ref, ...props }) {
  return <input {...props} ref={ref} />;
}
```

- **<Context> как провайдер**: Вместо <Context.Provider>.

```jsx
<ThemeContext value="dark">{children}</ThemeContext>
```

- **Cleanup для ref**: Возврат функции из ref callback для unmount.

## React Compiler

React Compiler — это **экспериментальный инструмент времени сборки** (Babel-плагин), представленный в React 19, который автоматически оптимизирует компоненты, избавляя разработчиков от ручной мемоизации через `useMemo`, `useCallback` и `React.memo`. Он анализирует код на основе **Rules of React** и генерирует оптимизированный JS, ускоряя рендер до 2–3x в реальных приложениях (Instagram использует в продакшене).

### Rules of React (обязательные для работы)

Компилятор работает **только** если код следует строгим правилам:

1. **Не мутировать state/props**: `state.push()` → `setState([...state, item])`
2. **Стабильные зависимости**: функции в deps без `useCallback` запрещены
3. **Не читать локальные переменные**: `let x = 1; useEffect(() => console.log(x))`
4. **StrictMode обязателен** — выявляет нарушения

**ESLint-plugin-react-compiler** ловит нарушения:

```bash
npm i eslint-plugin-react-compiler -D
```

### Установка

```bash
npm i babel-plugin-react-compiler -D
```

**Vite** (`vite.config.js`):

```js
import react from "@vitejs/plugin-react";

export default {
  plugins: [
    react({
      babel: {
        plugins: [["babel-plugin-react-compiler", {}]],
      },
    }),
  ],
};
```

**Next.js**: Встроенная поддержка с `next.config.js`:

```js
module.exports = {
  experimental: {
    reactCompiler: true,
  },
};
```

### Ограничения

✅ **Оптимизирует**:

- `useMemo`/`useCallback` → заменяет

## Другие улучшения

React 19 значительно упростил работу с метаданными, стилями, скриптами, предзагрузкой и кастомными элементами, сделав код более декларативным без сторонних библиотек.

### Поддержка метаданных документа

```
React автоматически перемещает `<title>`, `<meta>`, `<link>` из JSX в `<head>`, даже из вложенных компонентов. Работает с SSR, дедуплицируется.
```

```jsx
function ProductPage({ product }) {
  return (
    <>
      <title>{product.name} — Магазин</title>
      <meta name="description" content={product.description} />
      <meta property="og:image" content={product.image} />
      <h1>{product.name}</h1>
      {/* контент */}
    </>
  );
}
```

**Преимущества**: Нет react-helmet, улучшенное SEO, динамические метатеги по роутам. Несколько `<title>` — последний побеждает.

### Поддержка таблиц стилей

```
`<link rel="stylesheet">` и `<style>` с атрибутом `precedence` ("default"/"high") автоматически оптимизируются: preload, дедупликация, правильный порядок.
```

```jsx
function App() {
  return (
    <>
      <link rel="stylesheet" href="/global.css" precedence="default" />
      <style precedence="high">{`
        .header { position: sticky; }
      `}</style>
      <Header />
      <Main />
    </>
  );
}
```

```
**Логика**: React добавляет preload `<link>` в `<head>` до рендера, группирует стили по precedence. В SSR — в правильном порядке. Несколько одинаковых CSS — один тег.
```

### Поддержка асинхронных скриптов

```
`<script async>` можно размещать где угодно в JSX — React дедуплицирует, в SSR добавляет в `<head>` с приоритетом.
```

```jsx
function Analytics() {
  return <script async src="https://analytics.example.com/script.js" />;
}

function App() {
  return (
    <>
      <Analytics /> {/* один раз в DOM */}
      <Analytics /> {/* дубликат игнорируется */}
      <Main />
    </>
  );
}
```

**Особенности**: Несколько вызовов — один `<script>`. Async скрипты не блокируют гидратацию. Поддержка `crossOrigin`, `fetchPriority`.

### Поддержка предварительной загрузки ресурсов

Новые API: `preload()`, `prefetchDNS()`, `preconnect()`, `preinit()` для шрифтов, скриптов, изображений. Вызывать на сервере/клиенте.

```jsx
// В корневом layout или page
import { preload, preinit, prefetchDNS } from "react-dom";

prefetchDNS("fonts.googleapis.com");
preload("/fonts/inter.woff2", { as: "font", type: "font/woff2" });
preinit("/analytics.js", { as: "script" });

function Page() {
  return <div>Страница с предзагруженными ресурсами</div>;
}
```

**API**:

- `preload()` — загрузить ресурс с низким приоритетом
- `preinit()` — загрузить + выполнить (скрипты/CSS)
- `preconnect()` — TCP-соединение заранее
  В SSR генерирует `<link rel="preload/connect">`.

### Поддержка пользовательских элементов (Custom Elements)

Полная совместимость с Web Components. Примитивные props → attributes на сервере, объекты → properties на клиенте.

```jsx
function App() {
  return (
    <>
      <my-counter count={5} disabled={false} />
      <my-chart data={chartData} /> {/* data как property */}
      <my-video src="video.mp4" controls />
    </>
  );
}
```

**Логика**:

- **Сервер**: `{count: 5}` → `count="5"`, объекты игнорируются
- **Клиент**: все props как properties + attributes
- Lifecycle: `connectedCallback()` при mount
  Проходит все тесты Custom Elements Everywhere.

### Практический пример (Next.js стиль)

```jsx
function Layout({ children }) {
  preinit("/styles.css", { as: "style" });
  prefetchDNS("cdn.example.com");

  return (
    <>
      <title>Мой магазин</title>
      <link rel="icon" href="/favicon.ico" />
      <link rel="stylesheet" href="/styles.css" precedence="default" />
      <script async src="https://cdn.example.com/analytics.js" />

      <header>
        <my-nav />
      </header>

      <main>{children}</main>
    </>
  );
}
```
