# Основы Linux

## Основные разделы файловой системы

| Папка    | Назначение                           | Примеры файлов / содержимого                               |
| :------- | :----------------------------------- | :--------------------------------------------------------- |
| `/`      | Корень файловой системы              | Все остальные каталоги                                     |
| `/bin`   | Базовые команды                      | `ls`, `cp`, `mv`, `cat`, `bash`                            |
| `/sbin`  | Админские утилиты                    | `ip`, `fsck`, `mount`, `reboot`                            |
| `/boot`  | Файлы загрузки                       | `vmlinuz`, `initrd.img`, `grub/`                           |
| `/dev`   | Устройства                           | `sda`, `tty`, `null`, `random`                             |
| `/etc`   | Конфиги системы                      | `passwd`, `hosts`, `ssh/sshd_config`, `fstab`              |
| `/home`  | Домашние папки пользователей         | `/home/nikita/`, документы, загрузки, настройки приложений |
| `/root`  | Домашняя папка root                  | Конфиги root, shell history                                |
| `/lib`   | Библиотеки для программ              | `libc.so`, модули ядра                                     |
| `/usr`   | Пользовательские программы и ресурсы | `usr/bin/`, `usr/lib/`, `usr/share/`                       |
| `/var`   | Изменяемые данные                    | `log/`, `cache/`, `spool/`, базы данных сервисов           |
| `/tmp`   | Временные файлы                      | Временные файлы программ, кэши на время работы             |
| `/proc`  | Виртуальная инфа о системе           | `cpuinfo`, `meminfo`, папки процессов `1234/`              |
| `/sys`   | Инфо о ядре и устройствах            | Параметры устройств и драйверов                            |
| `/mnt`   | Временное монтирование               | Вручную подключённые диски или разделы                     |
| `/media` | Съёмные носители                     | Флешки, внешние диски, CD/DVD                              |
| `/opt`   | Дополнительное ПО                    | Сторонние программы, например отдельные пакеты             |
| `/srv`   | Данные сервисов                      | Файлы web-, ftp- и других сервисов                         |

## Root и sudo

В Debian дистрибутивах (Ubuntu) отключен root, и доступ к нему можно получить с помощью команды `sudo`.

Чтобы посмотреть есть ли у пользователя права root:

```bash
sudo whoami
```

Если вы видите `root` в ответе, то у вас есть права root.

## Bash (Bourne-Again SHell)

Баш - это интерактивная командная строка. В ней можно вводить команды и получать на них ответ.

- `Ctrl + A` - переход на начало строки (также кнопка `Home`)
- `Ctrl + U` - удаление текущей строки
- `Ctrl + C` - прервать выполнение команды
- `;` - разделитель команд

### tty

tty - это терминал. В Linux есть несколько терминалов, и каждый из них может быть активен или неактивен. Чтобы узнать, какой терминал активен:

```bash
tty
```

Чтобы переключиться на другой терминал, надо нажать `Ctrl + Alt + F1`, `Ctrl + Alt + F2`, ..., `Ctrl + Alt + F6`. В Ubuntu 1 и 2 терминалы графические, остальные текстовые.

Вот так можно создать новый терминал, куда можно перейти с помощью `Ctrl + Alt + F12`:

```bash
sudo openvt -c 12 login
```

А так можно создать новый терминал, и сразу переключиться в него:

```bash
sudo openvt -sc 13 /bin/bash
```

Чтобы вернуться на существующий 13-ый терминал:

```bash
sudo chvt 13
```

### apt

apt - это пакетный менеджер для Debian-дистрибутивов. С его помощью можно устанавливать, удалять и обновлять пакеты.

Чтобы установить пакет:

```bash
sudo apt install <package_name>
```

Чтобы удалить пакет:

```bash
sudo apt remove <package_name>
```

## Доступ по SSH (Secure Shell)

Чтобы можно было подключаться к машине по SSH, нужно установить и запустить ssh-server:

```bash
sudo apt update
sudo apt install openssh-server
sudo systemctl enable --now ssh
```

Теперь надо узнать IP-адрес машины:

```bash
ip a
```

И подключиться к машине через клиент Putty.

### ls

ls - это команда для просмотра содержимого директории.

- `ls` - список файлов в текущей директории
- `ls -a` - список файлов в текущей директории, включая скрытые файлы
- `ls -l` - список файлов в текущей директории, включая права доступа, владельца и размер файла
- `ls -lh` - список файлов в текущей директории, включая права доступа, владельца и размер файла в читаемом виде (например, 4.0K, 1.0M)

## Выключение и перезагрузка

### poweroff

```bash
aniketos@aniketos-VirtualBox:/$ poweroff
```

### shutdown

```bash
aniketos@aniketos-VirtualBox:/$ shutdown -h 19:30 [сообщение]
```

```bash
aniketos@aniketos-VirtualBox:/$ shutdown -h now
```

Для перезагрузки:

```bash
aniketos@aniketos-VirtualBox:/$ shutdown -r now
```
