# Работа с файлами

## Типы файлов

- **`d`**: папка, внутри неё лежат файлы и другие каталоги.
- **`l`**: ссылка-указатель на другой файл или каталог.
- **`b`**: устройство, которое работает с данными **блоками**; обычно это диски и разделы.
- **`c`**: устройство, которое работает **потоково/посимвольно**; например терминалы, `null`, `random`.

### Примеры в системе

- `d` — `/home`, `/etc`, `/usr`.
- `l` — часто в `/usr/bin/...` или свои ссылки, созданные через `ln -s`.
- `b` — диски вроде `/dev/sda`, `/dev/nvme0n1`.
- `c` — `/dev/tty`, `/dev/null`, `/dev/random`.

## Потоки (каналы)

В Linux у каждой команды обычно есть три стандартных потока: **stdin** — ввод, **stdout** — обычный вывод, **stderr** — вывод ошибок. Перенаправление позволяет отправлять эти потоки не “в терминал по умолчанию”, а в файл, в другую команду или в специальный канал.

### Базовые операторы

- `>` — перенаправить stdout в файл, перезаписав его.
- `>>` — дописать stdout в конец файла.
- `<` — взять stdin из файла.
- `2>` — перенаправить stderr.
- `|` — конвейер: передать stdout одной команды на stdin другой.

### Конвейеры

Сначала `ps aux` выведет список процессов, а `grep` отфильтрует строки с `nginx`:

```bash
$ ps aux | grep nginx
```

Сначала `cat` читает файл, `grep 500` оставляет строки с кодом 500, `wc -l` считает количество строк:

```bash
cat access.log | grep 500 | wc -l
```

## Утилиты для работы с файлами

### cat - concatenate FILE(s), or standard input, to standard output With no FILE, or when FILE is -, read standard input

Чтение из файла:

```bash
cat filename
```

Создание файла:

```bash
$ cat > file.txt
21311311313
dsf
eeeeeeeeeeeeeeeee
<Ctrl + D>
```

Добавить строки в файл:

```bash
$ cat >> file.txt
111111
<Ctrl + D>
```

Завершающее слово:

```bash
$ cat<<END! > out3.txt
> 1111
> 222
> END!
$ cat out3.txt
1111
222
```

Объединение файлов:

```bash
$ cat file1.txt file2.txt > out.txt
```

### head - output the first part of files

```bash
$ head -n 2 file.txt
```

### tail - output the last part of files

```bash
$ tail -n 20 /var/log/auth.log
```

Читать логи в режиме реального времени:

```bash
$ tail -fn0 /var/log/auth.log
```

### more - file perusal filter for CRT viewing

```bash
$ more file.txt
```

### less - opposite of more

```bash
$ less file.txt
```

### touch - update the access and modification times of each FILE to the current time

```bash
$ ls -li out2.txt
666479 -rw-rw-r-- 1 aniketos aniketos 40 May 30 13:20 out2.txt
$ touch out2.txt
$ ls -li out2.txt
666479 -rw-rw-r-- 1 aniketos aniketos 40 May 30 17:22 out2.txt
```

### cp - copy files and directories

```bash
$ cp out2.txt folder1/folder2
```

### mv - move (rename) files

```bash
$ mv out2.txt folder1
```

### rm - remove files or directories

```bash
$ rm folder1
rm: cannot remove 'folder1': Is a directory
$ rm -r folder1
```

### ln - make links between files

```bash
$ ln file.txt hardlink.txt
$ ln -s file.txt symlink.txt
```

### mkdir - create the given DIRECTORY(ies) if they do not exist

```bash
$ mkdir -p folder1/folder2
```

### rmdir - remove the DIRECTORY(ies), if they are empty

```bash
$ rmdir folder1
```

## Жесткие и символьные ссылки

### Жёсткая ссылка

- Ссылается на тот же самый inode, то есть на те же данные на диске.
- Если удалить “оригинальный” файл, данные останутся, пока есть хотя бы одна жёсткая ссылка.
- Работает только в пределах одной файловой системы.
- Обычно нельзя делать на директории.

### Символьная ссылка

- Содержит путь к файлу.
- Если удалить или переместить исходный файл, ссылка станет “битой”.
- Можно делать на файлы и каталоги.
- Можно между разными файловыми системами.

### Пример

```bash
ln file.txt hardlink.txt
ln -s file.txt symlink.txt
```

- `hardlink.txt` — ещё одно имя для того же файла.
- `symlink.txt` — ярлык, который указывает на `file.txt`.

### Как это почувствовать

Если изменить содержимое через жёсткую ссылку, изменится тот же файл.
Если удалить `file.txt`, то `hardlink.txt` продолжит работать, а `symlink.txt` сломается.

### Короткая таблица

| Свойство                          | Жёсткая ссылка | Символьная ссылка |
| :-------------------------------- | :------------- | :---------------- |
| Хранит                            | inode          | путь              |
| Работает через удаление исходника | да             | нет               |
| Между файловыми системами         | нет            | да                |
| На директории                     | обычно нет     | да                |
| Похожа на ярлык                   | нет            | да                |

## Поиск файлов

### find - search for files in a directory hierarchy

```bash
$ find /home -name out3.txt
/home/aniketos/out3.txt
/home/aniketos/Pictures/out33/out3.txt
/home/aniketos/Pictures/out3.txt
```

Можно найти все жесткие ссылки файла:

```bash
$ ls -li out3.txt
666481 -rw-rw-r-- 1 aniketos aniketos 9 May 30 13:28 out3.txt
$ find /home -inum 666481
/home/aniketos/out3.txt
/home/aniketos/hlout3.txt
```

Или еще проще:

```bash
$ find /home -samefile out3.txt
/home/aniketos/out3.txt
/home/aniketos/hlout3.txt
```

### locate - find files by name, quickly

```bash
$ locate out3*
/home/aniketos/hlout3.txt
/home/aniketos/out3.txt
/home/aniketos/Pictures/out3.txt
/home/aniketos/Pictures/out33/out3.txt
```

### which - locate a command

```bash
$ which ls
/usr/bin/ls
```

Ищет только исполняемые файлы, и только тут:

```bash
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games:/usr/local/games:/snap/bin
```

### tree - list files in a tree-like format

```bash
$ tree
.
├── file.txt
├── folder1
│   └── folder2
│       └── file.txt
└── out2.txt
```
