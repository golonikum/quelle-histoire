# Текстовые редакторы

## sed

Заменить:

```bash
$ sed -e 's/string2/stringX/g' testfile1
string1
stringX
string3
$ cat testfile1
string1
string2
string3
```

Удалить вхождение:

```bash
$ sed -e '/string2/d' testfile1 testfile2
string1
string3
```

Удалить по номеру строки:

```bash
$ sed -e '1d' testfile1
string2
string3
```

Выбрать 6 строк:

```bash
$ sed -n '1,6p' /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
sync:x:4:65534:sync:/bin:/bin/sync
games:x:5:60:games:/usr/games:/usr/sbin/nologin
```

Выбрать 6 строк и взять только 3 из них:

```bash
$ sed -n '1,6p; 3q' /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
```

Убрать все комментарии и пустые строки:

```bash
$ sed -e '/ *#/d; /^$/d' sshd_config
Include /etc/ssh/sshd_config.d/*.conf
KbdInteractiveAuthentication no
UsePAM yes
X11Forwarding yes
PrintMotd no
AcceptEnv LANG LC_* COLORTERM NO_COLOR
Subsystem       sftp    /usr/lib/openssh/sftp-server
```

Ключ `-i` делает реальную замену:

```bash
$ sed -i '/ *#/d; /^$/d' sshd_config
```

## vim

### Самое важное

- `Esc` — выйти в normal mode.
- `i` — начать ввод текста (войти в режим редактирования).
- `:10` — перейти на 10-ю строку.
- `:w` — сохранить.
- `:q` — выйти.
- `:wq` — сохранить и выйти (`Shift + Z + Z`).
- `:q!` — выйти без сохранения (`Shift + Z + Q`).

### Навигация

- `h`, `j`, `k`, `l` — влево, вниз, вверх, вправо.
- `w` — следующее слово.
- `b` — предыдущее слово.
- `0` — начало строки.
- `$` — конец строки.
- `gg` — начало файла.
- `G` — конец файла.

### Редактирование

- `x` — удалить символ.
- `dd` — удалить строку.
- `yy` — копировать строку.
- `p` — вставить после курсора (`P` - вставить перед курсором).
- `u` — отменить действие (`Ctrl + r` — вернуть отмену).

### Выделение

- `v` — выделять символы.
- `V` — выделять строки.
- `Ctrl + v` — прямоугольное выделение.
- После выделения можно использовать `y` для копирования или `d` для удаления.

### Поиск

- `/слово` — поиск вперёд.
- `n` — следующее совпадение.
- `N` — предыдущее совпадение.

### Замена

- `:s/старое/новое/` — заменит первое вхождение `старое` на `новое` в текущей строке.
- `:s/старое/новое/g` — заменит все вхождения `старое` на `новое` в текущей строке.
- `:%s/старое/новое/g` — заменит все вхождения `старое` на `новое` во всем файле.
- `:%s/старое/новое/gc` — заменит все вхождения `старое` на `новое` во всем файле (с подтверждением каждой замены).
- `:1,10s/старое/новое/g` — заменит все вхождения `старое` на `новое` в первых 10 строках.

### Полезные команды

- `:set number` — показать номера строк.
- `:set nonumber` — скрыть номера строк.
- `:help` — открыть справку.
- `:help keyword` — помощь по конкретному слову.
