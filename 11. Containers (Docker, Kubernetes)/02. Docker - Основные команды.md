# Основные команды Docker

**Основные команды Docker** — шпаргалка для 95% задач разработки и эксплуатации.

## 🐳 **Базовые (ежедневно)**

```bash
docker --version          # Версия
docker info               # Статус Docker
docker system prune -a    # Очистка всего (⚠️)
```

## 📦 **Образы (Images)**

| Команда             | Что делает            | Пример                       |
| :------------------ | :-------------------- | :--------------------------- |
| `docker pull nginx` | Скачать образ         | `docker pull node:20-alpine` |
| `docker images`     | Список образов        | `-a` — все (промежуточные)   |
| `docker build .`    | Собрать из Dockerfile | `-t apk:latest`              |
| `docker push`       | Отправить в реестр    | `docker push registry/apk`   |
| `docker rmi`        | Удалить образ         | `docker rmi apk:latest`      |

## 🐳 **Контейнеры (Containers)**

| Команда                  | Что делает            | Пример                            |
| :----------------------- | :-------------------- | :-------------------------------- |
| `docker run -d nginx`    | **Запустить**         | `-p 80:80 --name web`             |
| `docker ps`              | **Список запущенных** | `-a` — все контейнеры             |
| `docker stop web`        | **Остановить**        | `docker stop $(docker ps -q)`     |
| `docker rm web`          | **Удалить**           | `-f` — принудительно              |
| `docker exec -it web sh` | **Зайти внутрь**      | `/bin/sh` или `/bin/bash`         |
| `docker logs web`        | **Логи**              | `-f` — следить в реальном времени |

## 📊 **Мониторинг**

```bash
docker stats              # CPU/RAM всех контейнеров
docker inspect web        # Детальная инфа JSON
docker port web           # Порты контейнера
docker top web            # Процессы внутри
```

## 🗄️ **Volumes (данные)**

```bash
docker volume ls          # Список
docker volume create data # Создать
docker run -v data:/app   # Подключить
docker run -v ./src:/app  # Локальная папка
```

## 🌐 **Сети (Networks)**

```bash
docker network ls         # Список
docker network create apk # Создать
docker run --network apk  # Подключить
```

## 🐙 **Docker Compose (мультиконтейнер)**

```bash
docker-compose up -d      # Запустить стек
docker-compose down       # Остановить + удалить
docker-compose logs       # Логи всех сервисов
docker-compose ps         # Статус сервисов
docker-compose build      # Пересобрать образы
```

## 💡 **Читы для жизни**

```bash
# Убить все контейнеры
docker stop $(docker ps -aq)

# Удалить все остановленные
docker container prune -f

# Очистить всё (образы, контейнеры)
docker system prune -af

# Следить за логами Next.js
docker-compose logs -f frontend

# Зайти в контейнер Node.js
docker exec -it apk-frontend sh
```
