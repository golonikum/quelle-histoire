# SOLID

SOLID — 5 принципов объектно-ориентированного программирования для создания масштабируемого, поддерживаемого кода (Роберт Мартин, "Дядя Боб").

## 1. Single Responsibility Principle (SRP)

Модуль должен отвечать за одного и только за одного актора.

Актор - человек или группа людей, которые имеют общие интересы.

Класс/компонент = 1 задача. `UserCard` ≠ `UserApi` + `UserUI`.

```
// ❌ UserCard делает ВСЁ
const UserCard = ({user}) => {
  const saveUser = async () => fetch('/api/user') // API
  return <div>{user.name} <button onClick={saveUser}>Сохранить</button></div> // UI
}

// ✅ Разделяем
const useUserApi = () => { /* API */ }
const UserCard = ({user, onSave}) => <div>...</div> // Только UI
```
