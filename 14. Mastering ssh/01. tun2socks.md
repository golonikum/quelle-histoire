# tun2socks

## SOCKS Прокси

### Файл .ssh/config

```
Host m2
    HostName 95.54.41.231
    User aniketos
    Port 8879

Host ubuntu
    HostName 192.168.0.11
    User aniketos
    Port 22
```

### Создание ssh-туннеля на TCP-порт 9999

```
ssh m2 -D 9999 -N
```

### Настройка SOCKS5 прокси в Mozilla Firefox

В FF можно в настройках задать SOCKS5 Прокси (`127.0.0.1:9999`), тогда все запросы будут через него.

## Глобальный туннель

Но лучше задать глобальный туннель, чтобы все запросы вообще были через SOCKS5 Прокси. Для этого надо установить `tun2socks`.

### Установка tun2socks

Для корректной работы tun2socks в Windows нужно скачть Wintun и положить `wintun.dll` рядом с файлом `tun2socks.exe`.

### Запуск tun2socks

```
tun2socks-windows-386_v2.6.0.exe --device wintun --proxy socks5://127.0.0.1:9999 --interface "Беспроводная сеть"
```

### Настройка маршрутизации

```
netsh interface ipv4 set address name="wintun" source=static addr=192.168.123.1 mask=255.255.255.0
netsh interface ipv4 set dnsservers name="wintun" static address=8.8.8.8 register=none validate=no
netsh interface ipv4 add route 0.0.0.0/0 "wintun" 192.168.123.1 metric=1

// Исключите маршрут до SSH-сервера (надо ли?)
// route add <SSH_SERVER_IP> mask 255.255.255.255 <YOUR_DEFAULT_GATEWAY>
```

Можно через `.bat` файл:

```
@echo off
REM Настройка Wintun интерфейса для OpenVPN
REM Запускать от имени администратора!

echo Configure static IP for IF wintun...

netsh interface ipv4 set address name="wintun" source=static addr=192.168.123.1 mask=255.255.255.0
if %errorlevel% neq 0 (
    echo Error set IP! Code: %errorlevel%
    pause
    exit /b %errorlevel%
)

echo Configure DNS server...

netsh interface ipv4 set dnsservers name="wintun" static address=8.8.8.8 register=none validate=no
if %errorlevel% neq 0 (
    echo Error when config DNS! Code: %errorlevel%
    pause
    exit /b %errorlevel%
)

echo Add default route...

netsh interface ipv4 add route 0.0.0.0/0 "wintun" 192.168.123.1 metric=1
if %errorlevel% neq 0 (
    echo Error add default route! Code: %errorlevel%
    pause
    exit /b %errorlevel%
)

echo Configure succeeded!
pause
```

### Проблема с git

Проблема с `GitHub` в `VS Code` типичная: `Git` использует `SSH`, который не идёт автоматически через `SOCKS5`, даже если весь трафик маршрутизируется через `tun2socks`. Надо настроить `Git`:

```
git config --global core.sshCommand "ssh -o ProxyCommand='plink -socks 127.0.0.1:1080 -nc %h:%p'"
```

### Проблема с Claude Code

Причина оказалась в том, что Node.js предпочитал IPv6-адрес, который через tun2socks не маршрутизируется — а --dns-result-order=ipv4first заставил его ходить по IPv4, как это делал работающий curl. Если ещё не закрепили переменную постоянно — сделайте, чтобы не задавать её каждый раз:

```powershell
[Environment]::SetEnvironmentVariable("NODE_OPTIONS","--dns-result-order=ipv4first","User")
```

## Автоматизированный скрипт на PowerShell

```powershell
#Requires -Version 5.1
<#
.SYNOPSIS
    Автозапуск SSH-туннеля (ssh -D) + tun2socks + настройка wintun-интерфейса.

.DESCRIPTION
    Выполняет всю последовательность одной командой:
      1) ssh -D <порт>              — поднимает SOCKS5 на 127.0.0.1
      2) tun2socks                  — создаёт wintun-адаптер и заворачивает в SOCKS5
      3) netsh                      — IP, DNS и маршрут по умолчанию для wintun
    Ждёт готовности каждого этапа, а при выходе (Ctrl+C) корректно всё гасит.

.EXAMPLE
    .\tunnel.ps1 -SshHost root@203.0.113.10

.EXAMPLE
    .\tunnel.ps1 -SshHost root@vps.example.com -PhysIf "Беспроводная сеть" -ExcludeVpsRoute
#>

[CmdletBinding()]
param(
    # Куда подключаться: user@host или user@IP
    [Parameter(Mandatory = $true)]
    [string] $SshHost,

    [int]    $SshPort   = 22,
    [int]    $SocksPort = 9999,

    # Путь к tun2socks. По умолчанию — рядом со скриптом.
    [string] $Tun2Socks = "$PSScriptRoot\tun2socks-windows-386_v2.6.0.exe",

    # Физический интерфейс. Пусто = определить автоматически по default route.
    [string] $PhysIf    = "",

    [string] $TunIf     = "wintun",
    [string] $TunAddr   = "192.168.123.1",
    [string] $TunMask   = "255.255.255.0",
    [string] $Dns       = "8.8.8.8",

    # Сколько секунд ждать готовности SOCKS-порта и адаптера
    [int]    $Timeout   = 25,

    # Добавить /32-маршрут до VPS в обход туннеля (не обязательно, но не мешает)
    [switch] $ExcludeVpsRoute,

    # Не перезапускать автоматически при обрыве
    [switch] $NoRestart,

    [string] $LogDir    = "$env:TEMP\ssh-tun2socks"
)

$ErrorActionPreference = 'Stop'

# ---------------------------------------------------------------------------
# 0. Повышение прав (netsh требует администратора)
# ---------------------------------------------------------------------------
$identity  = [Security.Principal.WindowsIdentity]::GetCurrent()
$principal = New-Object Security.Principal.WindowsPrincipal($identity)
if (-not $principal.IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    Write-Host "Требуются права администратора, перезапускаю с UAC..." -ForegroundColor Yellow
    $argList = @('-NoProfile', '-ExecutionPolicy', 'Bypass', '-NoExit', '-File', "`"$PSCommandPath`"")
    foreach ($k in $PSBoundParameters.Keys) {
        $v = $PSBoundParameters[$k]
        if ($v -is [switch]) { if ($v.IsPresent) { $argList += "-$k" } }
        else                 { $argList += "-$k"; $argList += "`"$v`"" }
    }
    Start-Process -FilePath 'powershell.exe' -Verb RunAs -ArgumentList $argList
    exit
}

# ---------------------------------------------------------------------------
# Вспомогательные функции
# ---------------------------------------------------------------------------
function Write-Step { param([string]$Text) Write-Host "==> $Text" -ForegroundColor Cyan }
function Write-Ok   { param([string]$Text) Write-Host "    $Text" -ForegroundColor Green }
function Write-Warn { param([string]$Text) Write-Host "    $Text" -ForegroundColor Yellow }

function Wait-Condition {
    param([scriptblock]$Test, [int]$Seconds = 20, [int]$IntervalMs = 300)
    $sw = [Diagnostics.Stopwatch]::StartNew()
    while ($sw.Elapsed.TotalSeconds -lt $Seconds) {
        try { if (& $Test) { return $true } } catch { }
        Start-Sleep -Milliseconds $IntervalMs
    }
    return $false
}

function Resolve-HostAddress {
    param([string]$NameOrIp)
    $parsed = [ipaddress]::Any
    if ([ipaddress]::TryParse($NameOrIp, [ref]$parsed)) { return $NameOrIp }
    try {
        return ([System.Net.Dns]::GetHostAddresses($NameOrIp) |
                Where-Object AddressFamily -eq 'InterNetwork' |
                Select-Object -First 1).IPAddressToString
    } catch { return $null }
}

# ---------------------------------------------------------------------------
# 1. Определяем физический интерфейс и его шлюз ДО правки таблицы маршрутов
# ---------------------------------------------------------------------------
Write-Step "Определяю текущий маршрут по умолчанию"

$defRoute = Get-NetRoute -DestinationPrefix '0.0.0.0/0' -ErrorAction SilentlyContinue |
            Where-Object { $_.InterfaceAlias -ne $TunIf -and $_.NextHop -ne '0.0.0.0' } |
            Sort-Object RouteMetric, ifMetric |
            Select-Object -First 1

if (-not $defRoute) { throw "Не найден маршрут по умолчанию. Есть ли вообще интернет?" }

if (-not $PhysIf) { $PhysIf = $defRoute.InterfaceAlias }
$physGw = $defRoute.NextHop
Write-Ok "Интерфейс: $PhysIf, шлюз: $physGw"

$vpsHostName = $SshHost.Split('@')[-1]
$vpsIp       = Resolve-HostAddress $vpsHostName
if (-not $vpsIp) { throw "Не удалось определить IP для '$vpsHostName'" }
Write-Ok "VPS: $vpsHostName -> $vpsIp"

if (-not (Test-Path $Tun2Socks)) { throw "tun2socks не найден: $Tun2Socks" }
New-Item -ItemType Directory -Path $LogDir -Force | Out-Null

# ---------------------------------------------------------------------------
# Запуск / остановка туннеля
# ---------------------------------------------------------------------------
$script:SshProc  = $null
$script:TunProc  = $null
$script:RouteAdded = $false

function Start-Tunnel {

    # --- 1. ssh -D --------------------------------------------------------
    Write-Step "Поднимаю SSH-туннель (SOCKS5 на 127.0.0.1:$SocksPort)"

    if (Get-NetTCPConnection -LocalPort $SocksPort -State Listen -ErrorAction SilentlyContinue) {
        throw "Порт $SocksPort уже занят. Закройте старый ssh или укажите -SocksPort другой."
    }

    $sshArgs = @(
        '-N'
        '-D', "127.0.0.1:$SocksPort"
        '-p', "$SshPort"
        '-o', 'ExitOnForwardFailure=yes'
        '-o', 'ServerAliveInterval=15'
        '-o', 'ServerAliveCountMax=3'
        '-o', 'StrictHostKeyChecking=accept-new'
        $SshHost
    )
    $script:SshProc = Start-Process -FilePath 'ssh.exe' -ArgumentList $sshArgs `
                        -WindowStyle Hidden -PassThru `
                        -RedirectStandardError "$LogDir\ssh.log"

    if (-not (Wait-Condition -Seconds $Timeout -Test {
            Get-NetTCPConnection -LocalPort $SocksPort -State Listen -ErrorAction SilentlyContinue })) {
        throw "SOCKS-порт $SocksPort не открылся за $Timeout с. Смотрите $LogDir\ssh.log"
    }
    Write-Ok "SOCKS5 готов (PID $($script:SshProc.Id))"

    # --- 2. tun2socks -----------------------------------------------------
    Write-Step "Запускаю tun2socks"

    $tunArgs = @(
        '--device',    $TunIf
        '--proxy',     "socks5://127.0.0.1:$SocksPort"
        '--interface', $PhysIf
    )
    $script:TunProc = Start-Process -FilePath $Tun2Socks -ArgumentList $tunArgs `
                        -WindowStyle Hidden -PassThru `
                        -RedirectStandardOutput "$LogDir\tun2socks.log" `
                        -RedirectStandardError  "$LogDir\tun2socks.err.log"

    if (-not (Wait-Condition -Seconds $Timeout -Test {
            $a = Get-NetAdapter -Name $TunIf -ErrorAction SilentlyContinue
            $a -and $a.Status -eq 'Up' })) {
        throw "Адаптер '$TunIf' не появился за $Timeout с. Смотрите $LogDir\tun2socks.err.log"
    }
    Write-Ok "Адаптер '$TunIf' поднят (PID $($script:TunProc.Id))"

    # --- 3. netsh: адрес, DNS, маршрут ------------------------------------
    Write-Step "Настраиваю $TunIf"

    # адаптер может быть ещё "сырым" — даём netsh пару попыток
    $applied = Wait-Condition -Seconds 10 -IntervalMs 500 -Test {
        netsh interface ipv4 set address name="$TunIf" source=static addr=$TunAddr mask=$TunMask 2>&1 | Out-Null
        $LASTEXITCODE -eq 0
    }
    if (-not $applied) { throw "Не удалось задать IP-адрес для '$TunIf'" }
    Write-Ok "IP: $TunAddr / $TunMask"

    netsh interface ipv4 set dnsservers name="$TunIf" static address=$Dns register=none validate=no | Out-Null
    Write-Ok "DNS: $Dns"

    netsh interface ipv4 add route 0.0.0.0/0 "$TunIf" $TunAddr metric=1 | Out-Null
    Write-Ok "Маршрут по умолчанию через $TunIf"

    if ($ExcludeVpsRoute) {
        route add $vpsIp mask 255.255.255.255 $physGw metric 1 | Out-Null
        $script:RouteAdded = $true
        Write-Ok "Исключение: $vpsIp через $physGw"
    }

    ipconfig /flushdns | Out-Null

    # --- 4. Проверка ------------------------------------------------------
    try {
        $ip = (Invoke-WebRequest -Uri 'https://api.ipify.org' -UseBasicParsing -TimeoutSec 10).Content.Trim()
        if ($ip -eq $vpsIp) { Write-Ok "Внешний IP: $ip — трафик идёт через VPS" }
        else                { Write-Warn "Внешний IP: $ip (ожидался $vpsIp)" }
    } catch {
        Write-Warn "Не удалось проверить внешний IP: $($_.Exception.Message)"
    }
}

function Stop-Tunnel {
    Write-Host ""
    Write-Step "Останавливаю туннель"

    if ($script:RouteAdded) {
        route delete $vpsIp 2>&1 | Out-Null
        $script:RouteAdded = $false
    }

    foreach ($p in @($script:TunProc, $script:SshProc)) {
        if ($p -and -not $p.HasExited) {
            Stop-Process -Id $p.Id -Force -ErrorAction SilentlyContinue
        }
    }
    $script:TunProc = $null
    $script:SshProc = $null

    # маршруты и адрес исчезают вместе с адаптером, добиваем кэш DNS
    Start-Sleep -Milliseconds 500
    ipconfig /flushdns | Out-Null
    Write-Ok "Готово"
}

# ---------------------------------------------------------------------------
# Основной цикл
# ---------------------------------------------------------------------------
[Console]::TreatControlCAsInput = $true
try {
    Start-Tunnel
    Write-Host ""
    Write-Host "Туннель работает. Ctrl+C — выход." -ForegroundColor White

    while ($true) {
        Start-Sleep -Milliseconds 500

        if ([Console]::KeyAvailable) {
            $key = [Console]::ReadKey($true)
            if ($key.Key -eq 'C' -and $key.Modifiers -band [ConsoleModifiers]::Control) { break }
        }

        $dead = ($script:SshProc -and $script:SshProc.HasExited) -or
                ($script:TunProc -and $script:TunProc.HasExited)

        if ($dead) {
            if ($NoRestart) { Write-Warn "Соединение оборвалось, выхожу."; break }
            Write-Warn "Соединение оборвалось — перезапуск через 3 с..."
            Stop-Tunnel
            Start-Sleep -Seconds 3
            try { Start-Tunnel } catch { Write-Warn $_.Exception.Message; Start-Sleep -Seconds 5 }
        }
    }
}
finally {
    Stop-Tunnel
    [Console]::TreatControlCAsInput = $false
}
```
