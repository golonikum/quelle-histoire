# Next.js

**Next.js** — React-фреймворк для fullstack-приложений, созданный **Zeit (ныне Vercel)** в октябре 2016 года **Гильермо Раучем (Guillermo Rauch)** для решения проблем SEO и производительности SPA.

## История развития

- **2016**: Запуск v1.0 — SSR + file-system routing (pages/)
- **2018**: API Routes, `next/image` оптимизация
- **2020**: Переименование Zeit → Vercel, \$21M инвестиций
- **2021**: App Router (app/), React Server Components
- **2023**: Turbopack (Rust), ISR (Incremental Static Regeneration)
- **2025–2026**: Stage 3 polyfill, полная поддержка Temporal API

## Ключевые особенности

**1. Гибкий рендеринг:**

```
pages/     → Client-side + SSR/SSG
app/       → Server Components + Streaming
```

**2. File-system routing:**

```
app/
├── dashboard/
│   ├── page.tsx      → /dashboard
│   ├── layout.tsx    → Общий layout
│   └── loading.tsx   → Skeleton
└── api/
    └── users/route.ts → POST /api/users
```

**3. Оптимизации "из коробки":**

- Автоматическое code splitting
- `next/image` + WebP/AVIF
- Turbopack (100x быстрее webpack)
- Middleware для auth/redirects

**Эволюция**: От SSR-фреймворка → Fullstack React платформа с Turbopack и Vercel AI SDK. Используют Netflix, TikTok, Uber.

## Next 16

**Next.js 16** (стабильный релиз ~октябрь 2025) — фокус на скорости, стабильности Turbopack и новом программировании кэша. Вот **10 главных фич**.

### 🚀 **1. Turbopack по умолчанию (3–6x ускорение)**

```
npm run dev      # Turbopack автоматически
npm run build    # Turbopack для продакшена
```

- Fast Refresh: **85 мс** (vs 350 мс webpack)
- Холодный старт: **1.9 сек** (vs 8.2 сек)
- Build среднего проекта: **18 сек** (vs 62 сек)

### ⚡ **2. Cache Components (новая парадигма кэша)**

```tsx
"use cache"; // Компонент кэшируется навсегда

function CameraList() {
  const cameras = await fetchCameras(); // Кэшируется
  return <CameraGrid cameras={cameras} />;
}
```

### 🎯 **3. Partial Prerendering (PPR)**

Страница = статическая оболочка + динамические `<Suspense>` блоки:

```
app/dashboard/page.tsx
├── Статический HTML (0.1 сек из CDN)
├── <Suspense fallback={<Skeleton />}>
│   └── Динамические камеры (2–3 сек)
└── Клиентский JS (опционально)
```

### 🔧 **4. next.config.ts — нативный TypeScript**

```ts
// Без @types/next или tsconfig трюков
const nextConfig: NextConfig = {
  experimental: {
    turbo: { loaders: { ".ts": "ts-loader" } },
  },
};
export default nextConfig;
```

### 🛡️ **5. Server Actions API (`after()`, `forbidden()`)**

```ts
"use server";

export async function deleteCamera(formData: FormData) {
  await deleteFromDB(formData.get("id"));

  redirect("/dashboard"); // Автоматически после ответа
  // или
  forbidden(); // 403 без лишнего кода
}
```

### 🧠 **6. React Compiler (автоматическая оптимизация)**

```tsx
// Больше не нужен React.memo/useMemo/useCallback
function CameraGrid({ cameras }) {
  return cameras.map((camera) => <CameraCard key={camera.id} {...camera} />);
}
// Компилятор автоматически мемоизирует
```

### 📡 **7. Умная маршрутизация**

- **Layout deduplication**: Один layout для 50+ ссылок
- **Incremental prefetch**: Только hover/видимость
- **Route segments**: `/dashboard/[id]/cameras/[cameraId]`

### 📦 **8. Build Adapters API (alpha)**

```ts
// Собственный билд-пайплайн
export default createNextBuildAdapter({
  name: "custom-docker",
  adapt: async (buildManifest) => {
    /* Docker image */
  },
});
```

### 🎨 **9. next/image — новые дефолты**

```tsx
// minimumCacheTTL=4h, AVIF/WebP, localPatterns защита
<Image
  src="/camera-1.jpg"
  alt="Камера 1"
  fill
  quality={95} // Авто WebP/AVIF
/>
```

### 🔄 **10. Async Request APIs (обязательно await)**

```tsx
// ❌ Больше не работает
export default function Page({ params }) {
  return <div>{params.id}</div>; // undefined!
}

// ✅ Обязательный await
export default async function Page({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  return <div>{id}</div>;
}
```
