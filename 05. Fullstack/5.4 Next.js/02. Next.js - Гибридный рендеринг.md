# **Next.js 16: Гибридный рендеринг (Middle+/Senior уровень)**

Next.js 16 предлагает **7 гибридных стратегий** между **SSR** (каждый запрос) и **CSR** (клиент). Они сочетают **статический shell** + **динамические holes** с **fine-grained caching**.

## **1. Cache Components (`'use cache'`)** ⭐ **Основной**

**Статичный код + кэшированные данные** → **глобальный кэш на уровне app**.

```tsx
// next.config.ts
export default {
  cacheComponents: true, // Включает PPR + Cache Components
};
```

```tsx
// lib/categories.ts
async function getCategories() {
  "use cache"; // ✅ Кэшируется 24ч
  "cacheLife({ stale: 3600 })"; // Next 16.2+

  return db.categories.findMany();
}
```

```tsx
// app/products/page.tsx
export default async function Products() {
  const categories = await getCategories(); // 1 запрос на всех страницах!

  return (
    <div>
      <nav>
        {categories.map((c) => (
          <a>{c.name}</a>
        ))}
      </nav>{" "}
      {/* Instant */}
    </div>
  );
}
```

**Когда**: Статичные списки (категории, страны).

## **2. Partial Prerendering (PPR)**

**Static Shell + Dynamic Holes** → **мгновенный shell**, **streaming dynamic**.

```tsx
// app/product/[id]/page.tsx
export default function ProductPage({ params }: { params: { id: string } }) {
  return (
    <div>
      {/* Static Shell - кэшируется */}
      <header>Logo | Cart</header>

      {/* Dynamic Hole */}
      <Suspense fallback={<ProductSkeleton />}>
        <ProductDetails id={params.id} /> {/* SSR/stream */}
      </Suspense>

      <footer>Copyright</footer>
    </div>
  );
}
```

**Когда**: Product pages (статичный layout + динамичный контент).

## **3. Streaming + Suspense Boundaries**

**Параллельный рендеринг** → **каждый `<Suspense>` независим**.

```tsx
export default function Dashboard() {
  return (
    <div>
      <Suspense fallback={<UserSkeleton />}>
        <UserProfile /> {/* 500ms */}
      </Suspense>
      <Suspense fallback={<StatsSkeleton />}>
        <Stats /> {/* 2s */}
      </Suspense>
      <RecentActivity /> {/* Instant */}
    </div>
  );
}
```

**Когда**: Dashboard с разными fetch'ами.

## **4. Selective Hydration**

**Кэшированные компоненты** гидратируются **только при взаимодействии**.

```tsx
// components/HeavyChart.tsx
"use cache";
function HeavyChart() {
  const data = await getExpensiveData(); // Кэш!
  return <Chart data={data} />;
}
```

**next.config.ts:**

```ts
experimental: {
  selectiveHydration: true;
}
```

**Когда**: Тяжёлые графики, редко используемые.

## **5. Dynamic Imports + Lazy Loading**

**Code splitting** + **Suspense** → **load on demand**.

```tsx
import dynamic from "next/dynamic";

const HeavyEditor = dynamic(() => import("@/components/Editor"), {
  loading: () => <EditorSkeleton />,
  ssr: false, // CSR only
});

export default function PostEditor() {
  return <HeavyEditor />;
}
```

**Когда**: Редакторы, модалки.

## **6. ISR + On-Demand Revalidation**

**Статический + background updates**.

```tsx
// app/blog/[slug]/page.tsx
export const revalidate = 3600; // ISR 1ч

export async function generateStaticParams() {
  return db.posts.map((post) => ({ slug: post.slug }));
}
```

```ts
// app/api/revalidate/route.ts
export async function POST(req: Request) {
  revalidateTag("posts");
  revalidatePath("/blog/[slug]");
}
```

**Когда**: Blog, docs.

## **7. Cache Profiles (Next 16.2+)**

**Гибридные стратегии** одним атрибутом.

```tsx
// Компонент с несколькими профилями
async function UserList({
  cacheProfile,
}: {
  cacheProfile: "static" | "dynamic";
}) {
  if (cacheProfile === "static") {
    ("use cache");
    return db.users.findMany({ where: { public: true } });
  }

  // Dynamic
  const userId = cookies().get("user")?.value;
  return db.users.findMany({ where: { ownerId: userId } });
}
```

```tsx
// page.tsx
export const dynamic = "force-dynamic"; // или 'auto' | 'error'
```

## **Комбинированный пример (Production)**

```tsx
// app/dashboard/page.tsx - Идеальный гибрид
export default async function Dashboard() {
  // 1. Cache Component (global)
  const categories = await getCategories(); // 'use cache'

  return (
    <div>
      {/* 2. Static Shell */}
      <header>
        Logo |{" "}
        {categories.map((c) => (
          <NavLink>{c.name}</NavLink>
        ))}
      </header>

      <main className="grid grid-cols-3 gap-4">
        {/* 3. PPR Holes */}
        <Suspense fallback={<StatsSkeleton />}>
          <Stats /> {/* SSR */}
        </Suspense>

        <Suspense fallback={<ChartSkeleton />}>
          <RevenueChart /> {/* Heavy, lazy */}
        </Suspense>

        {/* 4. Dynamic List */}
        <Suspense fallback={<UsersSkeleton />}>
          <UserList /> {/* dynamic=force-dynamic */}
        </Suspense>
      </main>

      {/* 5. ISR Footer */}
      <Footer />
    </div>
  );
}
```

## **Производительность (TTFB/LCP)**

| Стратегия            | TTFB  | LCP   | Use Case |
| :------------------- | :---- | :---- | :------- |
| **Pure SSR**         | 800ms | 2s    | Admin    |
| **Cache Components** | 50ms  | 200ms | Catalog  |
| **PPR + Suspense**   | 50ms  | 800ms | Product  |
| **ISR**              | 10ms  | 100ms | Blog     |
| **CSR**              | 50ms  | 3s    | Editor   |

## **Выбор стратегии (Middle+/Senior)**

```
1. Статичные данные → 'use cache' + Cache Components
2. Layout/Nav → Cache Components (global)
3. User-specific → Suspense + SSR
4. Heavy JS → dynamic import + selective hydration
5. Редкие обновления → ISR + revalidateTag
6. Real-time → WebSocket + client-only
```
