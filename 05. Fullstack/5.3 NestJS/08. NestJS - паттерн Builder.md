# NestJS - паттерн Builder?

**Да, в NestJS Builder используется повсеместно** — это один из самых заметных паттернов в экосистеме. Вот ключевые места с примерами из официальной документации и практики.[^4][^9]

## 1. **Swagger/OpenAPI (DocumentBuilder)** — самый известный

```typescript
// main.ts
const config = new DocumentBuilder()
  .setTitle("Cats example")
  .setDescription("The cats API description")
  .setVersion("1.0")
  .addTag("cats")
  .addBearerAuth() // ← цепочка методов
  .build(); // ← финальный вызов

const document = SwaggerModule.createDocument(app, config);
SwaggerModule.setup("api", app, document);
```

## 2. **DTO с класс-валидацией (class-validator + class-transformer)**

```typescript
// create-user.dto.ts
export class CreateUserDto {
  @IsString()
  @IsNotEmpty()
  name: string;

  @IsEmail()
  email: string;

  @IsOptional()
  @IsNumber()
  age?: number;
}

// Использование в контроллере — автоматическая валидация
@Post()
create(@Body() createUserDto: CreateUserDto) {
  return this.usersService.create(createUserDto);
}
```

Это **имплицитный Builder** через декораторы — NestJS строит пайплайн трансформации/валидации.

## 3. **QueryBuilder в TypeORM** (встроен в NestJS)

```typescript
// users.service.ts
async findUsers(filters: any) {
  return this.userRepository
    .createQueryBuilder('user')
    .leftJoinAndSelect('user.posts', 'posts')
    .where('user.age > :age', { age: 18 })
    .andWhere('user.isActive = :active', { active: true })
    .orderBy('user.createdAt', 'DESC')
    .limit(10)
    .getMany();  // ← классический Builder!
}
```

## 4. **Прямая реализация Builder для сложных DTO**

```typescript
// user-builder.ts
export class UserBuilder {
  private data: Partial<User> = {};

  static create() {
    return new UserBuilder();
  }

  setName(name: string): UserBuilder {
    this.data.name = name;
    return this;
  }

  setEmail(email: string): UserBuilder {
    this.data.email = email;
    return this;
  }

  setRoles(roles: string[]): UserBuilder {
    this.data.roles = roles;
    return this;
  }

  build(): User {
    return new User(this.data);
  }
}

// Использование в сервисе
createUser() {
  const user = UserBuilder.create()
    .setName('Nikita')
    .setEmail('nikita@example.com')
    .setRoles(['admin', 'user'])
    .build();

  return this.userRepository.save(user);
}
```

## 5. **Пайплайны валидации/трансформации**

```typescript
// validation.pipe.ts
@Injectable()
export class ComplexValidationPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    // Множество шагов валидации
    return this.validateEmail(value)
      .then(this.validatePassword.bind(this))
      .then(this.transformData.bind(this))
      .catch((err) => {
        throw new BadRequestException(err);
      });
  }
}
```

## Когда в NestJS используют Builder

| Сценарий            | Пример                      | Зачем                  |
| :------------------ | :-------------------------- | :--------------------- |
| **Swagger/OpenAPI** | `DocumentBuilder()`         | Обязательный!          |
| **Базы данных**     | `QueryBuilder()`            | TypeORM/Sequelize      |
| **DTO с 5+ полями** | `UserBuilder.create()`      | Читаемость + типизация |
| **Микросервисы**    | `Transport.TCP().options()` | Сложная конфигурация   |
| **Валидация**       | Custom pipes                | Пошаговая обработка    |

## Практический пример под твой стек

```typescript
// Создание сложного заказа в e-commerce
export class OrderBuilder {
  private order: Partial<Order> = {
    items: [],
    shipping: {},
    payment: {},
  };

  static create() { return new OrderBuilder(); }

  addItem(productId: string, quantity: number) {
    this.order.items!.push({ productId, quantity });
    return this;
  }

  withShipping(address: AddressDto) {
    this.order.shipping = { address };
    return this;
  }

  withPayment(method: 'card' | 'cash', details: any) {
    this.order.payment = { method, details };
    return this;
  }

  build() {
    const order = new Order(this.order);
    // Валидация, нормализация...
    return order;
  }
}

// В сервисе
async createOrder(dto: CreateOrderDto) {
  const order = OrderBuilder.create()
    .addItem(dto.productId, dto.quantity)
    .withShipping(dto.shippingAddress)
    .withPayment('card', dto.cardDetails)
    .build();

  return this.orderRepository.save(order);
}
```

**Вывод**: Builder в NestJS — это не просто паттерн, а **философия фреймворка**. От Swagger до TypeORM — везде цепочки fluent API. Особенно полезно для твоих mid/senior-интервью, где спрашивают про архитектуру NestJS-приложений.
