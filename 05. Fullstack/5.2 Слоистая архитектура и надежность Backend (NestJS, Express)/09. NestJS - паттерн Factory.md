# NestJS - паттерн Factory

Паттерн **Factory** в NestJS используется для динамического создания объектов, сервисов или провайдеров на основе конфигурации, типа или условий. Это встроено в DI-контейнер через `useFactory`, а также реализуется через кастомные фабричные сервисы.[^1][^3]

## 1. **useFactory в модулях (официальный способ)**

Самое частое использование — динамическое создание провайдеров при импорте модуля:

```typescript
// database.module.ts
@Module({})
export class DatabaseModule {
  static forRoot(options: { type: "mysql" | "postgres"; config: any }) {
    const dbProvider = {
      provide: "DATABASE_CONNECTION",
      useFactory: (configService: ConfigService) => {
        const type = options.type;

        if (type === "mysql") {
          return new MysqlConnection(options.config);
        }
        if (type === "postgres") {
          return new PostgresConnection(options.config);
        }
        throw new Error("Unknown DB type");
      },
      inject: [ConfigService],
    };

    return {
      module: DatabaseModule,
      providers: [dbProvider],
      exports: [dbProvider],
    };
  }
}

// Импорт в AppModule
@Module({
  imports: [
    DatabaseModule.forRoot({
      type: process.env.DB_TYPE,
      config: dbConfig,
    }),
  ],
})
export class AppModule {}
```

## 2. **Factory Service (сервис-фабрика)**

Создаём `@Injectable()` сервис, который возвращает разные реализации интерфейса:

```typescript
// notification.interface.ts
export interface NotificationService {
  send(message: string): Promise<void>;
}

// email-notification.service.ts
@Injectable()
export class EmailNotificationService implements NotificationService {
  async send(message: string) {
    console.log(`Email sent: ${message}`);
  }
}

// sms-notification.service.ts
@Injectable()
export class SmsNotificationService implements NotificationService {
  async send(message: string) {
    console.log(`SMS sent: ${message}`);
  }
}

// notification.factory.ts
@Injectable()
export class NotificationFactory {
  constructor(
    @Inject("EMAIL_NOTIFICATION")
    private emailService: EmailNotificationService,
    @Inject("SMS_NOTIFICATION")
    private smsService: SmsNotificationService,
  ) {}

  create(type: "email" | "sms"): NotificationService {
    return {
      email: this.emailService,
      sms: this.smsService,
    }[type];
  }
}
```

**Использование в контроллере:**

```typescript
@Controller("notify")
export class NotificationController {
  constructor(private factory: NotificationFactory) {}

  @Post(":type/:message")
  async send(
    @Param("type") type: "email" | "sms",
    @Param("message") message: string,
  ) {
    const service = this.factory.create(type);
    await service.send(message);
  }
}
```

## 3. **Abstract Factory (расширенный)**

Для создания семейств связанных объектов:

```typescript
// logger.interface.ts
export interface LoggerFactory {
  getLogger(context: string): Logger;
  getMetrics(): MetricsService;
}

// production.factory.ts
@Injectable()
export class ProductionLoggerFactory implements LoggerFactory {
  getLogger(context: string) {
    return new ProductionLogger(context);
  }
  getMetrics() {
    return new PrometheusMetrics();
  }
}

// development.factory.ts
@Injectable()
export class DevelopmentLoggerFactory implements LoggerFactory {
  getLogger(context: string) {
    return new ConsoleLogger(context);
  }
  getMetrics() {
    return new DebugMetrics();
  }
}
```

## 4. **Factory Provider с токенами**

```typescript
// app.module.ts
@Module({
  providers: [
    {
      provide: "DRIVER_FACTORY",
      useFactory: (config: ConfigService) => {
        const driverType = config.get("DRIVER_TYPE");
        return new DriverFactory(driverType);
      },
      inject: [ConfigService],
    },
    DriverFactory,
    RedisDriver,
    MongoDriver,
  ],
  exports: ["DRIVER_FACTORY"],
})
export class DriverModule {}
```

## 5. **Практический пример: Платёжные шлюзы**

```typescript
// payment-gateway.interface.ts
export interface PaymentGateway {
  process(amount: number, currency: string): Promise<PaymentResult>;
}

// stripe.gateway.ts
@Injectable()
export class StripeGateway implements PaymentGateway {
  async process(amount: number, currency: string) {
    // Stripe API call
    return { id: "stripe_123", status: "success" };
  }
}

// yandex.gateway.ts
@Injectable()
export class YandexGateway implements PaymentGateway {
  async process(amount: number, currency: string) {
    // Yandex API call
    return { id: "yandex_123", status: "success" };
  }
}

// payment.factory.ts
@Injectable()
export class PaymentGatewayFactory {
  private gateways = new Map<string, PaymentGateway>();

  constructor(
    @Inject("STRIPE") stripe: StripeGateway,
    @Inject("YANDEX") yandex: YandexGateway,
  ) {
    this.gateways.set("stripe", stripe);
    this.gateways.set("yandex", yandex);
  }

  getGateway(gateway: string): PaymentGateway {
    const instance = this.gateways.get(gateway);
    if (!instance) {
      throw new Error(`Unknown gateway: ${gateway}`);
    }
    return instance;
  }
}
```

## Когда использовать в NestJS

| Сценарий                                  | Factory | Альтернатива       |
| :---------------------------------------- | :------ | :----------------- |
| **Драйверы БД** (`mysql`, `postgres`)     | ✅      | Dynamic modules    |
| **Уведомления** (`email`, `sms`, `push`)  | ✅      | `@Inject()` токены |
| **Платёжные шлюзы**                       | ✅      | `useFactory`       |
| **Логгеры** (`console`, `file`, `sentry`) | ✅      | ConfigService      |
| **Простой switch** (2-3 случая)           | ❌      | Обычный сервис     |

## Преимущества в NestJS

- **✅ OCP**: добавляем новый драйвер без изменения кода
- **✅ DI-friendly**: фабрики — `@Injectable()`
- **✅ TypeScript**: полная типизация интерфейсов
- **✅ Тестирование**: легко мокать фабрику
- **✅ Конфигурация**: `process.env.DRIVER_TYPE`

**В твоём fullstack-стеке**: Factory идеален для микросервисов с разными хранилищами, платёжными системами или notification-каналами.
