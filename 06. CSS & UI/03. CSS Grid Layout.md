## 🧱 **CSS Grid Layout — Полное руководство (Middle+/Senior)**

### **🎯 Что такое CSS Grid**

**CSS Grid** — **двумерная система координат** для создания **сеточной верстки**. Работает с **строками И колонками одновременно**, в отличие от **Flexbox** (одномерный).

```
Flexbox: Горизонталь ИЛИ вертикаль
Grid:    Горизонталь + вертикаль = 2D
```

### **📐 1. Основные термины (must know)**

```
Грид-контейнер (.grid) ← содержит
├─ Грид-линии (1 │ 2 │ 3 │ 4) ← границы ячеек
├─ Грид-треки (колонки/строки)
├─ Грид-ячейки (1x1)
├─ Грид-полосы (объединенные ячейки │──│)
└─ Грид-элементы (.item1, .item2)
```

**Визуализация**:

```
1 │ 2 │ 3 │ 4    ← грид-линии (всего 5 линий = 4 колонки)
────────────
│ 1 │ 2 │ 3 │    ← грид-треки (колонки)
│───┼───┼───┤
│ 4 │ 5 │ 6 │    ← грид-ячейки
────────────
Линия 5
```

### **🚀 2. Создание Grid контейнера**

#### **Базовый Grid (3 колонки)**

```css
.grid {
  display: grid; /* ✅ Создать грид */
  grid-template-columns: 1fr 2fr 1fr; /* 3 колонки: 33% 66% 33% */
  grid-template-rows: 100px 200px; /* 2 строки */
  gap: 20px; /* Отступы между ячейками */
}
```

#### **HTML**

```html
<div class="grid">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

**Результат**:

```
[^1][  2  ][^3]
[^4][  5  ][^6]
```

### **🔢 3. grid-template-columns/rows — размеры треков**

| Единица        | Описание                         | Пример               |
| :------------- | :------------------------------- | :------------------- |
| **`px`**       | Фиксированная ширина             | `200px 100px`        |
| **`fr`**       | **Доля свободного пространства** | `1fr 2fr` = 33%/66%  |
| **`%`**        | Проценты от контейнера           | `25% 50%`            |
| **`auto`**     | По содержимому                   | `auto 1fr`           |
| **`minmax()`** | Диапазон                         | `minmax(150px, 1fr)` |

#### **repeat() — повторение**

```css
grid-template-columns: repeat(3, 1fr); /* 3 колонки по 1fr */
grid-template-columns: repeat(
  auto-fill,
  200px
); /* Столько, сколько поместится */
```

#### **auto-fit vs auto-fill**

```css
.auto-fill {
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  /* ❌ Пустые колонки остаются */
}

.auto-fit {
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  /* ✅ Пустые колонки схлопываются */
}
```

### **📍 4. Размещение элементов (позиционирование)**

#### **Способ 1: grid-column / grid-row (сокращенный)**

```css
.item1 {
  grid-column: 1 / 3;
} /* 1-я линия → 3-я линия (2 колонки) */
.item2 {
  grid-row: 1 / 3;
} /* 1-я строка → 3-я строка (2 строки) */
.item3 {
  grid-area: 1 / 2 / 3 / 4; /* row-start / col-start / row-end / col-end */
}
```

#### **Способ 2: span (по количеству ячеек)**

```css
.wide-item {
  grid-column: span 2; /* Занимает 2 колонки */
  grid-row: span 3; /* Занимает 3 строки */
}
```

### **🗺️ 5. grid-template-areas — визуальная карта**

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header  header"
    "sidebar main    ads"
    "footer  footer  footer";
  gap: 10px;
  height: 100vh;
}
```

```css
.header {
  grid-area: header;
}
.sidebar {
  grid-area: sidebar;
}
.main {
  grid-area: main;
}
.ads {
  grid-area: ads;
}
.footer {
  grid-area: footer;
}
```

**Результат**:

```
[HEADER HEADER HEADER]
[SIDEBAR MAIN ADS]
[FOOTER FOOTER FOOTER]
```

### **🎯 6. Выравнивание (Alignment)**

#### **Контейнерное выравнивание**

```css
.grid {
  justify-content: center; /* Горизонтальное центрирование */
  align-content: center; /* Вертикальное центрирование */
  place-content: center center; /* Сокращение */
}
```

#### **Выравнивание элементов в ячейках**

```css
.grid {
  justify-items: center; /* Все элементы по центру ячейки */
  align-items: center; /* По вертикали */
  place-items: center; /* Сокращение */
}

.item {
  justify-self: start; /* Этот элемент влево */
  align-self: end; /* Этот элемент вниз */
}
```

### **📱 7. Адаптивный Grid (без Media Queries)**

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
  /* 1-6 колонок автоматически в зависимости от ширины */
}
```

### **🔥 8. Продвинутые техники (Senior)**

#### **Именованные линии**

```css
.grid {
  grid-template-columns:
    [sidebar-start] 250px
    [main-start] 1fr
    [main-end sidebar-end] 250px;
}

.sidebar {
  grid-column: sidebar-start / sidebar-end;
}
```

#### **Авто-размещение (grid-auto-flow)**

```css
.grid {
  grid-auto-flow: column; /* Заполнять строки → колонки */
  grid-auto-columns: 200px; /* Размер новых колонок */
}
```

#### **Subgrid (CSS Subgrid)**

```css
.parent-grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

.subgrid {
  display: grid;
  grid-template-columns: subgrid; /* Наследует колонки родителя */
}
```

### **💎 9. Полный пример — Dashboard Layout**

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      .dashboard {
        display: grid;
        grid-template-columns: 250px 1fr 250px;
        grid-template-rows: auto 1fr auto;
        grid-template-areas:
          "header header header"
          "sidebar main ads"
          "footer footer footer";
        min-height: 100vh;
        gap: 1rem;
      }

      .header {
        grid-area: header;
        background: #4f46e5;
        color: white;
      }
      .sidebar {
        grid-area: sidebar;
        background: #f3f4f6;
      }
      .main {
        grid-area: main;
        background: white;
      }
      .ads {
        grid-area: ads;
        background: #fef3c7;
      }
      .footer {
        grid-area: footer;
        background: #1f2937;
        color: white;
      }
    </style>
  </head>
  <body>
    <div class="dashboard">
      <header class="header">Header</header>
      <nav class="sidebar">Sidebar</nav>
      <main class="main">Main Content</main>
      <aside class="ads">Ads</aside>
      <footer class="footer">Footer</footer>
    </div>
  </body>
</html>
```

### **⚡ 10. Grid vs Flexbox**

| Задача                | **Grid**                   | **Flexbox**                  |
| :-------------------- | :------------------------- | :--------------------------- |
| **2D layout**         | ✅ Header/sidebar/main     | ❌ Сложно                    |
| **Равномерная сетка** | ✅ `repeat(auto-fit, 1fr)` | ❌ `flex: 1`                 |
| **Однострочный ряд**  | ⚠️ Работает                | ✅ Идеально                  |
| **Центрирование**     | ✅ `place-items: center`   | ✅ `justify-content: center` |

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
  padding: 2rem;
}
```

**Формула**: **`display: grid` + `grid-template-columns: repeat(auto-fit, minmax())` + `gap`** 🚀
