## 📦 **CSS Container Queries — Контейнерные запросы**

**Container Queries** — это **революционная фича CSS** (2022), которая позволяет стилизовать **компоненты на основе размера их родительского контейнера**, а не размера viewport'а (как media queries). **Идеально для reusable компонентов**.

### **🎯 Проблема Media Queries**

```css
/* ❌ Media Query: зависит от ширины экрана */
@media (min-width: 768px) {
  .card {
    grid-template-columns: 1fr 1fr;
  }
}

/* Компонент .card ломается в узкой sidebar */
```

### **✅ Решение Container Queries**

```css
/* Родитель объявляет себя контейнером */
.card-wrapper {
  container-type: inline-size; /* Отслеживаем ширину */
}

/* Потомок реагирует на размер контейнера */
@container (min-width: 400px) {
  .card {
    grid-template-columns: 1fr 1fr; /* Работает везде! */
  }
}
```

### **🔧 1. container-type — объявление контейнера**

| Значение      | Что отслеживает               | Пример                        |
| :------------ | :---------------------------- | :---------------------------- |
| `inline-size` | **Ширина** (самое популярное) | `container-type: inline-size` |
| `block-size`  | **Высота**                    | `container-type: block-size`  |
| `size`        | **Ширина + высота**           | `container-type: size`        |
| `style`       | **CSS переменные**            | `container-type: style`       |

```css
.card-container {
  container-type: inline-size; /* Только ширина */
  container-name: card; /* Опциональное имя */
}
```

### **📐 2. @container — запрос к контейнеру**

```css
@container (min-width: 500px) {
  .card-content {
    font-size: 1.25rem;
  }
}

@container card (max-width: 300px) {
  /* По имени */
  .card {
    flex-direction: column;
  }
}

@container (inline-size > 20em) {
  /* Диапазон */
  .sidebar-menu {
    flex-wrap: wrap;
  }
}
```

### **💎 3. Полный практический пример (Card Component)**

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      /* 1. Контейнеры разных размеров */
      .main-grid {
        container-type: inline-size;
        container-name: main;
        max-width: 1200px;
        display: grid;
        gap: 20px;
      }

      .sidebar {
        container-type: inline-size;
        container-name: sidebar;
        width: 300px;
      }

      /* 2. Компонент адаптируется к контейнеру */
      .article-card {
        padding: 1rem;
        border: 1px solid #ccc;
      }

      /* 3. Стили для БОЛЬШИХ контейнеров */
      @container main (min-width: 600px) {
        .article-card {
          display: grid;
          grid-template-columns: 2fr 1fr;
          gap: 1rem;
        }
      }

      /* 4. Стили для МАЛЕНЬКИХ контейнеров */
      @container sidebar (max-width: 280px) {
        .article-card {
          font-size: 0.875rem;
          padding: 0.5rem;
        }

        .article-card img {
          width: 100%;
          height: 60px;
          object-fit: cover;
        }
      }
    </style>
  </head>
  <body>
    <!-- Широкий контейнер → двухколоночный layout -->
    <div class="main-grid">
      <article class="article-card">
        <div>
          <h2>Длинный заголовок статьи</h2>
          <p>Подробное описание...</p>
        </div>
        <img src="image.jpg" alt="preview" />
      </article>
    </div>

    <!-- Узкий контейнер → компактный вид -->
    <aside class="sidebar">
      <article class="article-card">
        <div>
          <h2>Короткий title</h2>
          <p>Кратко...</p>
        </div>
        <img src="image.jpg" alt="preview" />
      </article>
    </aside>
  </body>
</html>
```

### **🎨 4. Продвинутые возможности (Senior)**

#### **container-name — именованные контейнеры**

```css
.hero-section {
  container-type: inline-size;
  container-name: hero; /* Уникальное имя */
}

@container hero (min-height: 400px) {
  .hero-title {
    font-size: clamp(2rem, 5vw, 4rem);
  }
}
```

#### **Множественные контейнеры**

```css
.card-wrapper {
  container-type: inline-size block-size; /* И ширина И высота */
}

@container (aspect-ratio > 16/9) {
  .video-player {
    object-fit: cover;
  }
}
```

#### **Style Queries (CSS переменные)**

```css
.card {
  container-type: style; /* Отслеживаем CSS vars */
}

@container style(--theme: dark) {
  .card {
    background: #333;
    color: white;
  }
}
```

```html
<!-- Переменная меняется динамически -->
<div class="card" style="--theme: dark">Темная тема активирована</div>
```

### **⚡ 5. Container Queries vs Media Queries**

| Сценарий              | **Media Query**          | **Container Query**                |
| :-------------------- | :----------------------- | :--------------------------------- |
| Мобильный сайт        | ✅ `(max-width: 768px)`  | ❌ Зависит от viewport             |
| **Card в Grid**       | ❌ Все cards меняются    | ✅ `@container (min-width: 400px)` |
| **Sidebar компонент** | ❌ Ломается на мобильных | ✅ Адаптируется к sidebar          |
| **Dynamic layouts**   | ❌ Сложно                | ✅ Идеально                        |

### **🚀 7. Лучшие практики**

```css
/* ✅ 1. Всегда именовать сложные контейнеры */
.hero,
.card-grid,
.sidebar {
  container-type: inline-size name;
  container-name: hero; /* hero, card-grid, sidebar */
}

/* ✅ 2. Использовать диапазоны */
@container (20em < inline-size < 50em) {
  /* Идеальный размер */
}

/* ✅ 3. Комбинировать с clamp() */
@container (min-width: 30em) {
  font-size: clamp(1rem, 4cqw, 1.5rem);
}
```

### **🔥 Production кейсы**

1. **Dashboard cards** — разные layouts в зависимости от grid cell
2. **Sidebar menus** — компактный/расширенный вид
3. **Modal dialogs** — адаптация под размер модалки
4. **Product cards** — в catalog vs в single product page

### **✅ Ключевые отличия**

```
Media Query:  "Экран шире 768px → 2 колонки"
Container Query: "Родитель > 400px → 2 колонки"
```

**Формула**: **`container-type: inline-size` + `@container (min-width: 400px)`** 🚀
