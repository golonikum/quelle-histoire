# Tailwind CSS

`Tailwind CSS` — это **утилитарный CSS-фреймворк** с подходом "utility-first". Вместо готовых компонентов (как Bootstrap) предоставляет **атомарные классы** для каждого CSS-свойства.

## 🎯 **Основная идея**

```
<button class="px-6 py-3 bg-blue-500 text-white font-semibold rounded-lg hover:bg-blue-600">
  Кнопка
</button>
```

**Всё в одном месте** — без переключения между HTML и CSS.

## 🎛️ **Как это работает (под капотом)**

Tailwind — это **PostCSS-плагин**, который парсит ваши HTML/JSX-файлы и генерирует CSS **только для используемых классов**.

**🔧 Архитектура (слои):**

```
HTML/JSX → PostCSS → Tailwind → PurgeCSS → Final CSS (10KB)
```

## 🚀 **Основные фичи**

### **1. Утилитарные классы**

```
p-4    → padding: 1rem
text-xl → font-size: 1.25rem
bg-red-500 → background: #ef4444
w-full → width: 100%
flex → display: flex
```

### **2. Адаптивность (из коробки!)**

```
p-4 md:p-6 lg:p-8
↑mobile  ↑планшет  ↑десктоп
```

### **3. States (hover, focus, active)**

```
bg-blue-500 hover:bg-blue-600
focus:ring-2 focus:ring-blue-300
```

### **4. Система spacing/color**

```
Spacing: p-0 p-1 p-2 p-4 p-6 ... p-96 (4px шаги)
Colors:  bg-red-50 bg-red-100 ... bg-red-900 (9 градаций)
```

## 📱 **Быстрый старт (5 минут)**

```html
<!DOCTYPE html>
<html>
  <head>
    <script src="https://cdn.tailwindcss.com"></script>
  </head>
  <body class="bg-gradient-to-br from-blue-400 to-purple-600 min-h-screen">
    <div class="max-w-2xl mx-auto p-8">
      <h1 class="text-4xl font-bold text-white mb-8 text-center">
        Tailwind CSS Demo
      </h1>

      <div class="grid md:grid-cols-2 lg:grid-cols-3 gap-6">
        <div
          class="bg-white/80 backdrop-blur-xl rounded-2xl p-8 shadow-xl hover:shadow-2xl transition-all duration-300"
        >
          <h2 class="text-2xl font-bold text-gray-800 mb-4">Карточка 1</h2>
          <p class="text-gray-600 leading-relaxed">Стили прямо в HTML!</p>
          <button
            class="mt-6 px-6 py-3 bg-blue-500 text-white font-semibold rounded-xl hover:bg-blue-600 transition-all duration-200"
          >
            Клик!
          </button>
        </div>
      </div>
    </div>
  </body>
</html>
```

## ⚡ **Ключевые преимущества**

| Фича               | Описание                                             |
| :----------------- | :--------------------------------------------------- |
| **PurgeCSS**       | Удаляет неиспользуемые стили → **10KB** в продакшене |
| **Дизайн-система** | Консистентные отступы, цвета, радиусы                |
| **IntelliSense**   | Автодополнение в VSCode                              |
| **Компоненты**     | `@apply` для создания своих классов                  |
| **JIT Mode**       | Генерирует стили по требованию                       |

## 🎨 **Популярные паттерны**

```html
<!-- Кнопка (переиспользуемо) -->
<button
  class="px-4 py-2 bg-indigo-600 text-white rounded-lg shadow-md 
               hover:bg-indigo-700 focus:outline-none focus:ring-4 
               focus:ring-indigo-300 transition-all duration-200"
>
  Кнопка
</button>

<!-- Карточка -->
<div
  class="bg-white rounded-xl shadow-lg overflow-hidden hover:shadow-xl transition-shadow"
>
  <div class="p-6">
    <h3 class="text-xl font-bold text-gray-900 mb-2">Заголовок</h3>
    <p class="text-gray-600">Описание...</p>
  </div>
</div>

<!-- Flexbox сетка -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6">
  <!-- Карточки -->
</div>
```

## 🔧 **Установка в React/Next.js**

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

```js
// tailwind.config.js
module.exports = {
  content: ["./src/**/*.{js,jsx,ts,tsx}"],
  theme: { extend: {} },
  plugins: [],
};
```

## 📊 **Tailwind vs Bootstrap vs CSS**

| Характеристика          | Tailwind     | Bootstrap    | Vanilla CSS  |
| :---------------------- | :----------- | :----------- | :----------- |
| **Размер**              | 10KB (purge) | 150KB        | Зависит      |
| **Кастомизация**        | Полная       | Сложная      | Полная       |
| **Скорость разработки** | ⚡ Быстрая   | Быстрая      | Медленная    |
| **Гибкость**            | Максимальная | Ограниченная | Максимальная |
| **Кривая обучения**     | Средняя      | Легкая       | Низкая       |

**Tailwind = скорость + гибкость + современность!** 🚀
