# Tanstack Query

TanStack Query (ранее React Query) — это standalone библиотека для declarative data fetching, кэширования и синхронизации в React-приложениях. Она не требует Redux, работает из коробки с React 18+ и фокусируется на серверном состоянии (не локальном).[^10]

## Основные возможности

TanStack Query управляет запросами через `useQuery`/`useMutation`, автоматическое кэширование, stale-while-revalidate, refetching при фокусе/переподключении. Поддерживает TypeScript, пагинацию, infinite scroll, optimistic updates.[^1][^10]

- Глобальный кэш на уровне QueryClient.
- DevTools для инспекции запросов.
- ~14kb min+bundled, без зависимостей.

## Базовый пример

Установка: `npm i @tanstack/react-query`

```tsx
import {
  QueryClient,
  QueryClientProvider,
  useQuery,
  useMutation,
  useQueryClient,
} from "@tanstack/react-query";
import { useState } from "react";

const queryClient = new QueryClient();

interface Post {
  id: number;
  title: string;
}

const PostsList: React.FC = () => {
  // Query: автоматический fetch, cache, loading states
  const { data, isLoading, error, refetch } = useQuery({
    queryKey: ["posts"],
    queryFn: async () => {
      const res = await fetch("/api/posts");
      return res.json();
    },
  });

  const queryClient = useQueryClient();
  const addMutation = useMutation({
    mutationFn: (newPost: Partial<Post>) =>
      fetch("/api/posts", {
        method: "POST",
        body: JSON.stringify(newPost),
      }).then((res) => res.json()),
    onSuccess: () => {
      // Инвалидация и refetch
      queryClient.invalidateQueries({ queryKey: ["posts"] });
    },
  });

  const [title, setTitle] = useState("");

  if (isLoading) return <div>Загрузка...</div>;
  if (error) return <div>Ошибка: {(error as Error).message}</div>;

  return (
    <div>
      <input value={title} onChange={(e) => setTitle(e.target.value)} />
      <button
        onClick={() => addMutation.mutate({ title })}
        disabled={addMutation.isPending}
      >
        Добавить
      </button>

      <ul>
        {data?.map((post: Post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  );
};

// В App
function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <PostsList />
    </QueryClientProvider>
  );
}
```

## RTK Query vs TanStack Query

| Аспект        | RTK Query          | TanStack Query          |
| :------------ | :----------------- | :---------------------- |
| Зависимости   | Redux Toolkit      | Только React            |
| Setup         | Store + reducer    | QueryClient Provider    |
| Bundle size   | +9kb к RTK         | 14kb standalone         |
| Типизация TS  | Отличная (codegen) | Отличная                |
| DevTools      | Redux DevTools     | Собственные             |
| Когда выбрать | Redux в проекте    | Новый/greenfield проект |

**Для тебя (React/TS mid-level):** TanStack Query проще для новых проектов без Redux. RTK Query — если уже используешь RTK/Saga. Оба state-of-the-art в 2026.
