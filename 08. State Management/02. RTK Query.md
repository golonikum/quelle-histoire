# RTK Query

RTK Query — это мощный инструмент в составе Redux Toolkit для declarative data fetching, caching и синхронизации состояния в React-приложениях. Он упрощает работу с API, избавляя от ручного написания thunk'ов и логики кэширования.[^2][^3]

## Основные возможности

RTK Query генерирует хуки для запросов (queries) и мутаций (mutations), автоматически управляет кэшем, дедупликацией запросов и refetching'ом. Поддерживает TypeScript из коробки, оптимистичные обновления и инвалидацию кэша.[^3][^4]

- Автоматическое кэширование: один запрос на данные, даже если несколько компонентов их используют.
- Tags для инвалидации: `invalidateTags` после мутаций.
- Поллинг, subscriptions и кодогенерация из OpenAPI.

## Базовый пример

Определяете API slice один раз на app:

```typescript
import { createApi, fetchBaseQuery } from "@reduxjs/toolkit/query/react";

export const api = createApi({
  reducerPath: "api",
  baseQuery: fetchBaseQuery({ baseUrl: "/api" }),
  endpoints: (builder) => ({
    getPosts: builder.query<Post[], void>({
      query: () => "posts",
    }),
    addPost: builder.mutation<Post, Partial<Post>>({
      query: (newPost) => ({
        url: "posts",
        method: "POST",
        body: newPost,
      }),
      invalidatesTags: ["Posts"],
    }),
  }),
});

export const { useGetPostsQuery, useAddPostMutation } = api;
```

В store добавляете `api.reducer` и middleware.[^2]

## Интеграция с Redux

В Redux store:

```typescript
import { configureStore } from "@reduxjs/toolkit";
import { api } from "./api";

export const store = configureStore({
  reducer: { [api.reducerPath]: api.reducer },
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware().concat(api.middleware),
});
```

В компоненте: `const { data, isLoading } = useGetPostsQuery();` — всё готово.[^3][^2]

## Простой компонент со списком постов

```typescript
import React, { useState } from 'react';
import { useGetPostsQuery, useAddPostMutation } from './api'; // из вашего API slice

interface Post {
  id: number;
  title: string;
}

const PostsList: React.FC = () => {
  // Query хук: автоматически fetch'ит, кэширует, показывает loading/error
  const { data: posts, isLoading, error, refetch } = useGetPostsQuery();

  // Mutation хук: для POST/PUT/DELETE
  const [addPost] = useAddPostMutation();

  const [newTitle, setNewTitle] = useState('');

  const handleAddPost = async () => {
    if (!newTitle) return;

    try {
      // Mutation автоматически инвалидирует кэш по tags
      await addPost({ title: newTitle }).unwrap();
      setNewTitle('');
      refetch(); // optional, tags сделают refetch автоматически
    } catch (err) {
      console.error('Ошибка добавления:', err);
    }
  };

  if (isLoading) return <div>Загрузка постов...</div>;
  if (error) return <div>Ошибка: {error.message}</div>;

  return (
    <div>
      <h2>Посты</h2>
      <input
        value={newTitle}
        onChange={(e) => setNewTitle(e.target.value)}
        placeholder="Новый пост"
      />
      <button onClick={handleAddPost}>Добавить</button>

      <ul>
        {posts?.map((post: Post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>

      <button onClick={() => refetch()}>Обновить</button>
    </div>
  );
};

export default PostsList;
```

## Продвинутые опции

- **Lazy query** (ручной запуск): `const [trigger, { data, isLoading }] = useLazyGetPostsQuery();` — `trigger()` запускает запрос.
- **Skip**: `{ skip: !userId }` — не fetch'ить без условия.
- **Поллинг**: `{ pollingInterval: 30000 }` — каждые 30 сек.
- **Transform**: в endpoint `transformResponse: (response) => response.data.slice(0, 10)`.

Всё состояние (`isLoading`, `isFetching`, `isError`, `data`, `error`) доступно из хука автоматически.

## Когда использовать

Идеально для mid-level React/TS dev'ов вроде тебя: заменяет Redux Saga/Thunk для API. Минимальный bundle (~9kb сверху RTK), отличная DX с TS. Если в проекте уже RTK — переход простой.
