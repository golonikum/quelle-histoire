# Zustand

`Zustand` — это минималистичная библиотека для управления состоянием в React-приложениях (~1-2 КБ), которая использует хуки и не требует провайдеров или boilerplate-кода как Redux. Она идеальна для mid-level React/TS разработчиков вроде тебя: простая, типобезопасная, с отличной производительностью за счет селективных обновлений и встроенными middleware (persist, devtools, immer).

## Основные принципы

Zustand создает стор как хук с состоянием и actions. Компоненты подписываются только на нужные части (shallow equality), минимизируя ререндеры. Поддерживает TypeScript из коробки, асинхронные actions и комбинируется с Immer для мутабельного синтаксиса.

## Создание стора

```typescript
import { create } from "zustand";
import { devtools, persist } from "zustand/middleware";
import { immer } from "zustand/middleware/immer"; // для мутаций

interface BearState {
  bears: number;
  addBear: () => void;
  eat: (food: number) => void;
}

export const useBearStore = create<BearState>()(
  devtools(
    // DevTools
    persist(
      // Локальное хранение
      immer((set, get) => ({
        // Immer для мутаций
        bears: 0,
        addBear: () =>
          set((state) => {
            state.bears += 1;
          }),
        eat: (food: number) =>
          set((state) => {
            const eaten = get().bears * food;
            state.foodEaten = eaten;
          }),
      })),
      { name: "bear-storage" },
    ),
    { name: "bear-store" },
  ),
);
```

## Использование в компоненте

```tsx
import { useBearStore } from "./store";

const Bears = () => {
  // Селективная подписка — только на bears
  const bears = useBearStore((state) => state.bears);
  const addBear = useBearStore((state) => state.addBear);

  return (
    <div>
      <h1>{bears} медведей</h1>
      <button onClick={addBear}>Добавить медведя</button>
    </div>
  );
};
```

## Асинхронные actions

```typescript
const useUserStore = create((set) => ({
  users: [] as User[],
  fetchUsers: async () => {
    const res = await fetch("/api/users");
    set({ users: await res.json() });
  },
  createUser: async (user: Partial<User>) => {
    const res = await fetch("/api/users", {
      method: "POST",
      body: JSON.stringify(user),
    });
    const newUser = await res.json();
    set((state) => {
      state.users.push(newUser);
    });
  },
}));
```

## Сравнение с Redux/RTK

| Аспект      | Zustand              | Redux Toolkit            |
| :---------- | :------------------- | :----------------------- |
| Размер      | ~1 КБ                | ~10 КБ + RTK Query       |
| Boilerplate | 5 строк стора        | slice + store + provider |
| Провайдер   | Не нужен             | Обязателен               |
| Async       | Прямо в actions      | RTK Query/Thunk          |
| DevTools    | Middleware           | Redux DevTools           |
| Масштаб     | Малый-средний проект | Любой размер             |
| TS          | Простые типы         | Строгие типы             |

## Middleware

- `devtools()` — интеграция с Redux DevTools.
- `persist()` — localStorage/sessionStorage.
- `immer()` — мутации без spread-операторов.
- `subscribeWithSelector()` — тонкая подписка.

## Когда использовать

**Zustand для тебя:** UI-state (тема, модалки, формы), настройки, кэш API в средних проектах. Комбинируй с TanStack Query для серверного состояния. Переход с Redux — 10 минут.

**Не используй** для очень больших команд (>10 dev) без строгих правил — меньше "защитных" паттернов чем Redux.
